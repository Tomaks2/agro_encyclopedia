На відміну від кавуна, у дині (*Cucumis melo* L.) **чоловічі квітки закладаються на головному стеблі та пагонах першого порядку, а жіночі (плодоносні) квітки — ТІЛЬКИ на бокових пагонах II та III порядку**! ## 1.1. Біоморфологія та тип цвітіння *Cucumis melo*

<LightboxImage src="/photos/dynia/charts/65_zhinchi_kvitky_dyni.png" alt="Жіночі квітки дині та схема формування" />


Диня належить до родини Гарбузових (*Cucurbitaceae*). Це однорічна теплолюбна рослина із стрижневою кореневою системою, що проникає у ґрунт на глибину **2.0–2.5 метрів**.

```
                   Схема формування та прищипування дині
                  
                             [ Головне стебло ]
                                     │
      (Прищипка над 4-5-м листком)   ▼ (Зріз верхівки!)
                    ┌────────────────┴────────────────┐
                    │                                 │
           [ Пагін I порядку ]               [ Пагін I порядку ]
                    │                                 │
     (Прищипка над 5-6-м листком)             (Прищипка над 5-6-м листком)
                    │                                 │
        ┌───────────┴───────────┐         ┌───────────┴───────────┐
        │                       │         │                       │
 [ Пагін II порядку ]   [ Пагін II порядку ]  [ Пагін II порядку ]  [ Пагін II порядку ]
        │                       │         │                       │
        ▼                       ▼         ▼                       ▼
  [ 🌸 ЖІНОЧІ КВІТКИ ТА ЗАВ'ЯЗЬ ПЛОДІВ (Залишати по 1 плоду на пагін) ]
```

### Фізіологічні етапи формування:
1. **Перше прищипування:** Коли молода рослина сформує 4–5 справжніх листків, верхівку головного стебла відщипують. Це стимулює пробудження пазушних бруньок і ріст 2–3 бокових пагонів I порядку.
2. **Друге прищипування:** Пагони I порядку прищипують над 5–6-м листком. З їхніх пазух відростають бокові пагони II та III порядку, на яких масово закладаються маточні (жіночі) квітки з зав'яззю.
3. **Нормування зав'язі:** На кожному кущі залишають **не більше 3–5 плодів** (залежно від сорту). Усі дрібніші зав'язі та верхівки плодоносних пагонів прищипують над 2-м листком після плоду, щоб рослина не витрачала пластичні речовини.

### 📌 СХЕМА 276: БІОМОРФОЛОГІЯ ДИНІ *CUCUMIS MELO*

| Параметр | Характеристика |
| :--- | :--- |
| **Родина / вид** | Гарбузові (*Cucurbitaceae*) / *Cucumis melo* L. |
| **Життєва форма** | Однорічна теплолюбна ліана |
| **Корінь** | Стрижневий, глибина **2,0–2,5 м** (як у кавуна) |
| **Чоловічі квітки** | Головне стебло + пагони I порядку |
| **Жіночі квітки (плодоносні)** | **Тільки пагони II–III порядку** — головний закон дині |

### 📌 СХЕМА 277: АЛГОРИТМ ПРИЩИПУВАННЯ: ТРИ ЕТАПИ

| Етап | Коли | Що робимо | Результат |
| :--- | :--- | :--- | :--- |
| **1. Перше прищипування** | 4–5 справжніх листків | Відщипнути верхівку головного стебла | Пробудження пазушних бруньок → **2–3 пагони I порядку** |
| **2. Друге прищипування** | Пагони I порядку | Прищипнути **над 5–6-м листком** | Пагони II–III порядку → масове закладання жіночих квіток |
| **3. Нормування зав'язі** | При наливі | Залишити **3–5 плодів/кущ**; верхівки плодоносних пагонів над 2-м листком після плоду | Без відтоку пластики у зайвий ріст |

> 📌 **Головний підсумок розділу:** Головний агрономічний закон дині (*Cucumis melo*): чоловічі квітки закладаються на головному стеблі та пагонах I порядку, а жіночі плодоносні — тільки на пагонах II–III порядку. Без прищипування рослина нарощує довгі безплідні батоги, і зав'язування затримується на 3–4 тижні. Алгоритм: перше прищипування головного стебла на 4–5-му листку (2–3 пагони I порядку) → друге над 5–6-м листком пагонів I (жіночі квітки на II–III) → нормування 3–5 плодів/кущ із відщипуванням верхівок над 2-м листком після плоду. Коренева система стрижнева, до 2,0–2,5 м.
