<Callout type="important" title="Головні правила обрізки Смородини та Порічок">
При обрізці чорної смородини видаляють гілки віком **понад 3–4 роки**. При обрізці червоної та білої порічок видаляють гілки віком **понад 5–6 років**. Обрізка проводиться пізно восени після листопаду або рано навесні до розпускання бруньок (березень).
</Callout>

## 3.1. Формування класичного багаторічного куща

<LightboxImage src="/photos/smorodyna/charts/currant_infographic_04_bush_architecture.png" alt="Вікова архітектура куща" />


Дорослий продуктивний кущ повинен містити **12–15 скелетних гілок різного віку**:

- **Однорічні пагони заміщення (нулаші):** 3–4 шт.
- **2-річні гілки:** 3–4 шт.
- **3-річні гілки (ПІК ПРОДУКТИВНОСТІ):** 3–4 шт.
- **4-річні гілки (для чорної смородини — ЗРІЗАТИ; для порічок — залишати):** 3–4 шт.

```
                  Вікова структура куща Чорної смородини
  
  ┌─────────────────────────────────────────────────────────┐
  │  3-річні гілки (Основний урожай / 50%)                 │
  └────────────────────────────┬────────────────────────────┘
                               │
      ┌────────────────────────┼────────────────────────┐
      │                        │                        │
  ┌───┴───────────────┐  ┌─────┴───────────────┐  ┌─────┴───────────────┐
  │ 1-річні пагони    │  │ 2-річні гілки       │  │ 4-річні гілки       │
  │ (Заміна / 25%)    │  │ (Урожай / 25%)    │  │ (ВИДАЛИТИ заподлице!)│
  └───────────────────┘  └─────────────────────┘  └─────────────────────┘
```

## 3.2. Штамбова культура смородини та порічок

<LightboxImage src="/photos/smorodyna/charts/currant_infographic_05_standard_form.png" alt="Штамбова форма" />


Один із найпопулярніших методів у сучасному ландшафтному та присадибному ягідництві.

- **Підщепа:** Смородина золотиста (*Ribes aureum*).
- **Висота штамба:** **80 – 110 см**.
- **Переваги:** Ягоди не торкаються землі, зручний збір без нахиляння, крона ідеально провітрюється та висвітлюється сонцем, що повністю усуває ризик борошнистої роси та сірої гнилі.

### 📌 СХЕМА 196: ВІКОВА АРХІТЕКТУРА КУЩА (12–15 ГІЛОК) ТА ГРАНИЦІ ВИРІЗКИ

| Вік гілки | Кількість | Чорна смородина | Червона/Біла порічка |
| :--- | :--- | :--- | :--- |
| **Однорічні (нулаші)** | 3–4 шт. | Заміна, закладка врожаю | Заміна, утворення кільчаток |
| **2-річні** | 3–4 шт. | **Урожай / 25%** | Плодоношення кільчаток |
| **3-річні (ПІК)** | 3–4 шт. | **Основний урожай / 50%** | Пик кільчаток |
| **4-річні** | 3–4 шт. | **ЗРІЗАТИ заподлице** | Залишити — плодоносять |
| **5–6 років** | — | Не перетримувати | **ЗРІЗАТИ заподлице** |
| **Старше** | 0 | Загибання плодухи | Загибання плодухи |

**Час обрізки:** пізня осінь (після листопаду) або рання весна (березень, до сокоруху).

### 📌 СХЕМА 197: ШТАМБОВА ФОРМА: АНТИХВОРОБНИЙ ДИЗАЙН КРОНИ

| Параметр | Штамбова форма | Класичний кущ |
| :--- | :--- | :--- |
| **Підщепа** | Смородина золотиста (*Ribes aureum*) | Корневласний кущ |
| **Висота штамба** | **80–110 см** | 0 |
| **Контакт ягід із ґрунтом** | **Нульовий** | Прямий (ризик сірої гнилі) |
| **Провітрювання крони** | **Ідеальне** — крона ізольована | Середнє |
| **Борошниста роса та сіра гниль** | **Практично усунуті** | Регулярний ризик |
| **Ергономіка збору** | Збір стоячи, без нахилу | Нахил, кучкування |
| **Сфера застосування** | Ландшафт, присадиба, демо-ділянки | Промислове поле |

> 📌 **Головний підсумок розділу:** Обрізка смородини — це вікове балансування: кущ тримають на 12–15 скелетних гілках, де 3-річні дають 50% врожаю чорної смородини, а все старше 4 років вирізується заподлице; у порічок границя — 5–6 років, бо їхні кільчатки плодоносять довше. Обрізка — пізня осінь після листопаду або березень до сокоруху. Альтернатива — штамбова форма на підщепі *Ribes aureum* висотою 80–110 см: ягоди не торкаються землі, крона ізольована та провітрюється, що практично усуває борошнисту росу і сіру гниль і робить збір зручним стоячи.
