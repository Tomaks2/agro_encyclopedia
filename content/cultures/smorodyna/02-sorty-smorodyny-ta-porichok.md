<Callout type="tip" title="Критерії вибору сортів">
Для комерційного механізованого збору (на заморозку IQF) ключовими критеріями сорту є **сухий розрив ягоди**, одночасне дозрівання ягоди в китиці та міцність шкірки. Для десертного свіжого ринку вирішальними є **довжина китиці (понад 12–15 см)**, великий розмір ягоди (> 2,5–4,0 г) та високий Brix (> 10–12°).
</Callout>

## 2.1. Провідні сорти Чорної смородини (Ribes nigrum)

<LightboxImage src="/photos/smorodyna/charts/currant_infographic_03_markets.png" alt="Два ринки — два набори критеріїв" />


<InfoBlock type="gold" icon="🥇" title="1. Ювілейна Копаня — Україна (ІС УААН)">
- **Особливість:** Абсолютний бестселер української селекції.
- **Ягода:** Велика (2,0–3,5 г), одномірна, з сухим розривом, зріє одночасно.
- **Стійкість:** Висока стійкість до борошнистої роси, антракнозу та посухи.
- **Врожайність:** До **4,0–5,0 кг з куща** (18–22 т/га).

</InfoBlock>

<InfoBlock type="gold" icon="🥈" title="2. Краса Львова — Україна">
- **Особливість:** Дрібнонасінний десертний сорт із дуже соковитою солодкою м'якоттью.
- **Ягода:** Велика (2,5–4,5 г), блискучо-чорна, округла.
- **Призначення:** Ідеальний сорт для свіжого десертного споживання та виготовлення джемів.
</InfoBlock>

<InfoBlock type="gold" icon="👑" title="3. Бен Олдер (Ben Alder) / Бен Тиран (Ben Tirran) — Шотландія">
- **Призначення:** Промислові сорт-стандарти для механізованого комбайнового збору.
- **Особливість:** Кущі пряморослі, компактні, ягоди надзвичайно щільні, із високим вмістом вітаміну С та пектнатів.
</InfoBlock>

## 2.2. Провідні сорти Червоної та Білої Порічок (Ribes rubrum)

| Сорт | Тип / Колір | Довжина китиці | Характеристика |
| :--- | :--- | :--- | :--- |
| **Ровада (Rovada)** | Червона | **наддовга (15–20 см!)** | **Світовий комерційний еталон.** Ягода велика, прозора, яскраво-рубінова, довго висить на кущі без обсипання. |
| **Йонкер ван Тетс** | Червона | Середня (8–10 см) | Ультраранній сорт з високою зимостійкістю та десертним смаком. |
| **Світлиця** | Червона | Довга (12–14 см) | Український посухостійкий сорт з високим Brix. |
| **Біла Потапенко** | Біла | Середня (8–10 см) | Десертна біла порічка прозоро-кремового кольору, дуже солодка. |
| **Бланка (Blanka)** | Біла | Довга (12–15 см) | Високоврожайний пізній сорт білої порічки з великими ягодами. |

### 📌 СХЕМА 194: ДВА РИНКИ — ДВА НАБОРИ СОРТОВИХ КРИТЕРІЇВ

| Критерій | Механізований збір (IQF-заморозка) | Свіжий десертний ринок |
| :--- | :--- | :--- |
| **Сухий розрив ягоди** | **Обов'язковий** | Бажаний |
| **Одночасне дозрівання китиці** | **Критичний** | Не критичний |
| **Міцність шкірки** | **Висока** (транспортування) | Середня |
| **Довжина китиці** | Не важлива | **12–15+ см** |
| **Розмір ягоди** | Середній достатній | **2,5–4,0+ г** |
| **Brix** | Стандартний | **10–12°+** |
| **Еталонні сорти** | Бен Олдер, Бен Тиран, Ювілейна Копаня | Краса Львова, Ровада, Бланка |

### 📌 СХЕМА 195: СОРТОВА МАТРИЦЯ: ЧОРНА СМОРОДИНА VS ПОРІЧКИ

| Сорт | Вид | Ягода | Роль у господарстві |
| :--- | :--- | :--- | :--- |
| **Ювілейна Копаня** | Чорна, Україна | 2,0–3,5 г, сухий розрив, одночасне дозрівання | **Бестселер: 4–5 кг/кущ, 18–22 т/га**, стійка до роси та посухи |
| **Краса Львова** | Чорна, Україна | 2,5–4,5 г, десертна, дрібнонасінна | Свіжий ринок + джеми |
| **Бен Олдер / Бен Тиран** | Чорна, Шотландія | Щільна, високий вітамін C + пектинати | Промисловий стандарт для **комбайнів** |
| **Ровада** | Червона | **Китиця 15–20 см!**, рубінова, не обсипається | **Світовий комерційний еталон** червоної порічки |
| **Йонкер ван Тетс** | Червона | Китиця 8–10 см | Ультраранній, зимостійкий |
| **Світлиця** | Червона, Україна | Китиця 12–14 см, високий Brix | Посухостійкий десертний |
| **Біла Потапенко / Бланка** | Біла | Кремова, 8–15 см китиця | Десертна ніша: дуже солодка |

> 📌 **Головний підсумок розділу:** Вибір сорту Ribes — це вибір ринку, а не смаку: для механізованого збору на IQF-заморозку потрібен сухий розрив, одночасне дозрівання та міцна шкірка (Бен Олдер, Бен Тиран, Ювілейна Копаня з урожаєм до 18–22 т/га), а для свіжого десертного ринку — довгі китиці 12–15+ см, ягода 2,5–4,5 г та Brix 10–12° (Краса Львова, Ровада з китицею до 20 см). Ровада — світовий еталон червоної порічки, Ювілейна Копаня — флагман української селекції чорної.
