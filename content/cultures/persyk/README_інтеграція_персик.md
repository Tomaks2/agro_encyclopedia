# Інтеграція культури «Персик» — інструкція

Цей комплект доводить персик до рівня еталона (яблуня/груша): **19 розділів** (17 існуючих прокачано + 2 нові), **27 СХЕМ**, повний NextChapter-ланцюг, підсумки розділів, джерела з клікабельними URL, виправлені hero.

## 1. Заміна файлів культури

Видаліть усі старі `.md`-файли персика і покладіть на їхнє місце файли з цього комплекту:

```
content/cultures/persyk/   ← всі 19 файлів *.md
content/cultures/persyk/meta.json   ← новий meta.json (19 секцій)
```

Структура: `01-biolohiya.md`, `02-pidshchepy.md`, `03-sorty.md`, `04-posadka.md`, `05-obrizka.md`, `06-zhyvlennia.md`, `07-zeleni-operatsii.md`, `08-dohliad.md`, `09-poliv.md`, `10-khvoroby.md`, `11-zakhyst-kalendar.md`, `12-shkidnyky.md`, `13-zakhyst.md`, `14-scheplennia.md`, `15-zbir.md`, `16-pomylky.md`, `17-rehiony.md`, `18-mify.md` (НОВИЙ), `19-zamorozky.md` (НОВИЙ).

## 2. Що додано в існуючі 17 розділів

| Елемент | Опис |
|---------|------|
| СХЕМИ | 25 СХЕМ-шпаргалок (### 📌 СХЕМА N) наскрізної нумерації 1–25 |
| NextChapter | Ланцюг на всі 19 розділів: 01→02→…→17→18→19→01 |
| Підсумки | «📌 Підсумок розділу» в кінці кожного файлу (як у яблуні/груші) |
| Джерела | Клікабельні URL наукових джерел у кожному файлі (Penn State, Rutgers, MSU, НААН) |
| Hero | Виправлено дублі hero у 15/16/17 на унікальні тематичні фото |

## 3. Нові розділи

**18-mify.md** — 15 міфів про персик (як у яблуні/груші), СХЕМА 27 — шпаргалка «Міф → Реальність», NextChapter → 19.

**19-zamorozky.md** — весняні заморозки: критичні температури по фенофазах (Penn State/Rutgers: swollen bud -4,4°C → full bloom -2,8°C, post bloom -2,2°C), карта ризиків по регіонах України, алгоритм захисту до/під час/після заморозку, дії після пошкодження цвіту. СХЕМА 26. Для персика це найкритичніша тема — він цвіте найраніше.

## 4. Фото

Нові/замінені hero використовують існуючі фото з `public/images/cultures/persyk/` — нічого копіювати не потрібно. Дублів серед 19 hero немає.

## 5. Інфографіки (наступний етап)

13 наукових інфографік у затвердженому стилі (як у яблуні/груші) буде надано окремим повідомленням після скидання денної квоти генерації. Вони встановляться в `public/photos/persyk/charts/`, LightboxImage-вставки вже будуть вмонтовані в MD-файли — замінять відповідні файли на нові.

## 6. Перевірка

Перед деплоєм перевірте: нумерація СХЕМ без пропусків/дублів (grep "СХЕМА " *.md), NextChapter-ланцюг цілісний, slug у meta.json збігається з назвами файлів.
