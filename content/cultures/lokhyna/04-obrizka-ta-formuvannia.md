<Callout type="warning" title="Головна мета обрізки лохини">
Без щорічної обрізки кущ лохини швидко перевантажується дрібними гілочками, ягоди дрібнішають до розміру дикої лісової черниці, дозрівання затримується на 2 тижні, а врожайність падає. Обрізка лохини — це перш за все **нормування кількості квіткових бруньок** для отримання великої хрусткої ягоди.
</Callout>

## 4.1. Модель ідеального дорослого куща лохини

<LightboxImage src="/photos/lokhyna/charts/blueberry_infographic_22.png" alt="Вікова піраміда куща лохини" />


Дорослий кущ лохини віком понад 6–7 років повинен містити **від 8 до 12 скелетних гілок різного віку**:

- **1–2-річні пагони заміщення (без розгалужень):** 2–3 шт.
- **3–4-річні плодоносні гілки (ПІК ПРОДУКТИВНОСТІ):** 4–6 шт.
- **5-річні омолоджувані гілки:** 2–3 шт.
- **6-річні та старші гілки:** **0 шт. (ПОВНІСТЮ ВИДАЛЯЮТЬСЯ!)**

```
                 Ідеальна вікова структура куща лохини
  
                  ┌───────────────────────────────┐
                  │ 3-4 річні гілки (50% врожаю)  │
                  └───────────────┬───────────────┘
                                  │
      ┌───────────────────────────┼───────────────────────────┐
      │                           │                           │
  ┌───┴───────────────┐   ┌───────┴───────────┐   ┌───────────┴───────┐
  │ 1-2 річні пагони  │   │ 5-річні гілки     │   │ 6-річні гілки     │
  │ (Заміна / 20%)    │   │ (Омолодження/30%) │   │ (ВИДАЛИТИ / 0%)   │
  └───────────────────┘   └───────────────────┘   └───────────────────┘
```

## 4.2. Покроковий агрономічний алгоритм весняної обрізки (БЕРЕЗЕНЬ)

<InfoBlock type="gold" icon="1️⃣" title="Крок 1. Видалення гілок біля основи ґрунту">
Вирізають усе слабке, тонке («поросль»), звисаюче до землі та пошкоджене морозом гілля безпосередньо біля поверхні мульчі без залишення пеньків.
</InfoBlock>

<InfoBlock type="gold" icon="2️⃣" title="Крок 2. Видалення застарілих 6-річних гілок">
Гілки віком понад 5–6 років мають темну, розтріскану кору, лишайники та коротку дрібну плодуху. Їх вирізають заподлице для стимуляції росту нових потужних ростових пагонів від кореневої шийки.
</InfoBlock>

<InfoBlock type="gold" icon="3️⃣" title="Крок 3. Деталізація та проріджування плодухи у верхній ярус крони">
На 3–4-річних плодоносних гілках видаляють дрібні короткі гілочки довжиною менше 10 см (вони дають дрібну ягоду). На залишених сильних однорічних приростах залишають **не більше 4–6 квіткових бруньок** на гілочку, зрізаючи верхівку.
</InfoBlock>

### 📌 СХЕМА 184: ВІКОВА ПІРАМІДА ДОРОСЛОГО КУЩА ЛОХИНИ (8–12 ГІЛОК)

| Вік гілки | Кількість | Роль у кущі | Частка врожаю |
| :--- | :--- | :--- | :--- |
| **1–2 роки** (пагони заміщення) | 2–3 шт. | Вегетативний ріст, заміна | Підготовча база |
| **3–4 роки** (ПІК) | **4–6 шт.** | **50% усього врожаю** | Максимум |
| **5 років** (омолодження) | 2–3 шт. | Дозрівання до піку / вирізка | 30% і менше |
| **6+ років** | **0 шт. — видалити** | Гальма куща: темна кора, дрібна плодуха | 0% |

### 📌 СХЕМА 185: АЛГОРИТМ ВЕСНЯНОЇ ОБРІЗКИ (3 КРОКИ, БЕРЕЗЕНЬ)

| Крок | Дія | Критерій відбору |
| :--- | :--- | :--- |
| **1** | Вирізка слабкого гілля біля мульчі | Тонке, звисаюче, пошкоджене морозом — без пеньків |
| **2** | Вирізка застарілих 6-річних гілок заподлице | Темна розтріскана кора, лишайники, коротка плодуха → стимул ростовим пагонам |
| **3** | Деталізація плодухи верхнього ярусу | Видалити гілочки < 10 см; на сильних приростах **≤ 4–6 квіткових бруньок** |

| Помилка | Симптоми через 1–2 сезони |
| :--- | :--- |
| Обрізка відсутня | Ягода → розмір лісової черниці, дозрівання −2 тижні, падіння врожаю |
| Залишили 6-річні гілки | Кущ «старіє»: дрібна ягода, слабкі ростові пагони |
| Занадто агресивна вирізка | Втрата бази врожаю поточного року |

> 📌 **Головний підсумок розділу:** Обрізка лохини — це нормування квіткових бруньок, а не просто гігієна: без неї ягода міліє до розміру лісової черниці, а дозрівання відкладається на 2 тижні. Ідеальний дорослий кущ — 8–12 скелетних гілок різного віку, де 3–4-річні дають 50% врожаю, а все 6-річне і старше безжалісно видалюється заподлице. Три кроки весняної обрізки (березень): слабке гілля під мульчу, застаріла деревина заподлице, проріджування плодухи з максимумом 4–6 квіткових бруньок на гілочку.
