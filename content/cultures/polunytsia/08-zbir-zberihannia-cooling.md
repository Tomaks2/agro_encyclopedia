<Callout type="important" title="Неклімактеричний характер суниці">
Плоди суниці садової є **неклімактеричними** — після збору із куща вони повністю зупиняють процес накопичення цукрів та синтезу ароматичних речовин. Збір повинен проводитися строго у фазі 90–100% сортового забарвлення. При цьому швидкість псування суниці при температурі +20 °C у **20 разів вища**, ніж при температурі +0 °C. Затримка з охолодженням на 1 годину після збору скорочує термін реалізації плодів на 1 добу!
</Callout>

## 8.1. Критерії знімальної стиглості плодів

<LightboxImage src="/photos/polunytsia/charts/163_postzbyralnyi_lantziug.png" alt="Постзбиральний ланцюг" />


1. **Колір забарвлення:** 
   - *Для місцевого свіжого ринку:* **100% сортового забарвлення** (повнота смаку та аромату).
   - *Для далекого транспортування/експорту:* **75–90% забарвлення** (білий або рожевий кінчик ягоди).
2. **Рефрактометрія (°Brix):**
   - Мінімальний комерційний поріг: **7,5° Brix**.
   - Преміальний десертний стандарт: **> 9,0–11,0° Brix** (сорти Мурано, Клері, Мальвіна).
3. **Щільність м'якоті (Durofel Index):**
   - Показник Durofel > **60–65 units** (щільні сорти: Альбіон, Альба, Сан Андреас).

## 8.2. Правила та техніка дбайливого збору

- **Час збору:** Ранкові години (після висихання роси до початку спеки — з 6:00 до 11:00) або вечірній час. Збір ягід, нагрітих сонцем до +25...+30 °C, призводить до їх швидкого розм'якшення та «протікання соку».
- **Техніка відокремлення ягоди:** Ягоду збирають разом із чашечкою та **плодоніжкою довжиною 0,5–1,0 см**. Рука збирача не повинна торкатися самої м'якоті ягоди (збирач тримає тільки плодоніжку і легким прокручуванням відщипує її нігтем).
- **Пряме пакування у товарну тару (One-touch harvesting):** Суниця не витримує пересипання! Збирач укладає ягоду безпосередньо у кінцеву споживчу тару — пинетки (корзиночки) з перфорованого пластику або пресованого картону ємністю **250 г, 500 г або 1000 г**, які встановлені у пінеточній кліті.

```
                           Схема дбайливого збору суниці
  
                ( Рука тримає ТІЛЬКИ плодоніжку 0.5-1.0 см )
                                     │
                                     ▼
                            ┌────────────────┐
                            │    Чашечка     │
                            ├────────────────┤
                            │ Ягода (М'якоть)│ ◄── (Категорично заборонено
                            └────────────────┘      торкатися руками!)
                                     │
                                     ▼
                     [ Пряме пакування у пинетку 500г ]
```

## 8.3. Постзбиральне повітряне охолодження (Forced-Air Cooling)

Звичайне холодне приміщення не здатне швидко охолодити щільно укладену у ящики суницю (це займає до 24 годин).

- **Технологія Forced-Air Cooling (Примусове продування крижаним повітрям):** Ящики зі свіжозібраною суницею встановлюють в тунель охолодження, де через масив ягід під тиском примусово продувається повітря з температурою **+1,0...+1,5 °C** та відносною вологістю **90–95%**.
- **Швидкість охолодження:** Температура ягоди знижується з **+25 °C до +2 °C всього за 60–90 хвилин**.

```
                   Схема тунелю Forced-Air Cooling
  
     Повітря +1.5°C ──►  [ Палета з ящиками ] ──► [ Потужний вентилятор ]
     (Вологість 95%)     [  ягоди суниці    ]     (Всмоктування повітря)
                         [ Зниження t° за 1 годину від +25°C до +2°C ]
```

## 8.4. Параметри зберігання та модифікована атмосфера (MAP)

| Параметр | Стандартне зберігання | Зберігання в MAP-пакетах (Xtend®) |
| :--- | :--- | :--- |
| **Температура повітря** | **0...+0,5 °C** (Строго!) | **0...+0,5 °C** |
| **Відносна вологість** | **90 – 95%** | 95% |
| **Склад газу O₂** | 21% (Звичайне повітря) | **5 – 10%** |
| **Склад газу CO₂** | 0,04% | **10 – 15%** (Високий CO₂ пригнічує *Botrytis*) |
| **Граничний термін зберігання** | **3 – 7 діб** | **14 – 21 доба** |

| Ланка ланцюга | Параметр | Допустимий час | Наслідок порушення |
| :--- | :--- | :--- | :--- |
| **1. Збір** | 6:00–11:00, плодоніжка 0,5–1,0 см, one-touch у пинетку | — | Перегрів +25...+30 °C → «протікання» соку |
| **2. Транспортування до холодильника** | Затінені ящики на палетах, без повторного укладання | ≤ 1 година | Кожна затримка −1 доба товарного виду |
| **3. Forced-Air Cooling** | +1,0...+1,5 °C, RH 90–95%, продув крізь масив ящиків | 60–90 хвилин (з +25 до +2 °C) | Звичайне охолодження — до 24 годин = втрати |
| **4. Зберігання** | 0...+0,5 °C, RH 90–95%, стандартне | 3–7 діб | Вище +2 °C → експоненціальний ріст *Botrytis* |
| **5. MAP (Xtend® та аналоги)** | O₂ 5–10%, CO₂ 10–15% | **14–21 доба** | Високий CO₂ пригнічує Botrytis без хімії |

| Сценарій збуту | Оптимальний режим |
| :--- | :--- |
| **Фермерський ринок (свіжий, у день збору)** | Збір вранці → холодильний причіп → реалізація до 18:00 |
| **Ритейл / дистрибуція (1–3 доби)** | FAC одразу + 0...+0,5 °C + жорстка пинетка 250–500 г |
| **Експорт (до 3 тижнів)** | FAC + MAP-пакети + суворий температурний ланцюг 0...+0,5 °C |

> 📌 **Головний підсумок розділу:** Суниця — неклімактеричний плід: після збору вона не дозріває, не накопичує цукор і не стає смачнішою — лише псується, причому при +20 °C удвічі швидше, ніж при +0 °C. Тому постзбиральна логістика важливіша за агротехніку врожаю: збір із плодоніжкою 0,5–1,0 см без торкання м'якоті, one-touch у пинетку, Forced-Air Cooling за 60–90 хвилин і MAP-пакети подовжують життєвий цикл ягоди з 3–7 до 14–21 доби. Затримка охолодження на 1 годину коштує 1 добу реалізації.
