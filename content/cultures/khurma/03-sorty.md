<Callout type="important" title="Найважливіша класифікація хурми — за в'яжучістю таніну">
На відміну від будь-якої іншої плодової культури, для хурми ключовим є не стільки смак чи аромат, скільки **тип полімеризації таніну** — визначає, чи буде сорт їстівним прямо з дерева, чи його потрібно «дозрівати». Це визначає весь комерційний сценарій — ринок свіжого споживання vs переробка.
</Callout>

## 3.1. Чотирикласна система (JFTA, Japanese Fruit Tree Association)

Японська асоціація плодівництва класифікує всі сорти хурми за двома критеріями: 1) чи є сорт природно в'яжучим, 2) чи залежить усунення в'яжучості від насіння плоду.

| Клас | Абревіатура | Характеристика | Приклади |
| :--- | :--- | :--- | :--- |
| **Pollination Constant Non-Astringent** | **PCNA** | Незалежно від запилення та наявності насіння — НІКОЛИ не в'яжучий. Їстівний прямо з дерева при будь-якому кольорі | Дзіро, Фую (Фуйю), Імото |
| **Pollination Variable Non-Astringent** | **PVNA** | Не в'яжучий при наявності насіння (запилення відбулося). В'яжучий без насіння | Хіакуме (Кофуненосу) |
| **Pollination Constant Astringent** | **PCA** | ЗАВЖДИ в'яжучий незалежно від запилення. Потребує штучного дозрівання | Хачія, Нікітська Бордова |
| **Pollination Variable Astringent** | **PVA** | При наявності насіння — слабо в'яжучий. Без насіння — дуже в'яжучий | Шокорон, Мацумото |

## 3.2. Сорти типу PCNA (Їстівні з дерева — Комерційний стандарт)

<InfoBlock type="gold" icon="⭐" title="Дзіро (Jiro / Jiro Fuyu) — Стандарт свіжого ринку">
- **Походження:** Японія, префектура Кананагава, 1844 р.
- **Тип:** PCNA.
- **Форма плоду:** Приплюснута, квадровата у перерізі (4 чіткі ребра), характерна і впізнавана.
- **Маса плоду:** 200–280 г.
- **Цукристість зрілого плоду:** 16–20° Brix.
- **Термін дозрівання:** Середньоранній — жовтень.
- **Транспортабельність:** Висока (щільна м'якоть).
- **Чутливість до морозу:** До -12 °C (деревина). Рекомендована підщепа D. virginiana.
</InfoBlock>

<InfoBlock type="gold" icon="🌟" title="Фую (Fuyu / Suruga) — Класика PCNA">
- **Тип:** PCNA.
- **Маса плоду:** 150–200 г.
- **Форма:** Кругла, приплюснута зверху, без ребер.
- **Цукристість:** 14–17° Brix.
- **Термін дозрівання:** Жовтень — початок листопада.
- **Перевага:** Довготривале зберігання при 0 °C (до 90 днів) без втрати товарного вигляду.
</InfoBlock>

## 3.3. Сорти типу PVNA (В'яжучість залежить від запилення)

<InfoBlock type="orange" icon="🟤" title="Хіакуме (Kofunenoshu / Chocolate Persimmon)">
- **Тип:** PVNA.
- **Особливість:** При наявності насіння — м'якоть набуває темно-шоколадного кольору (Brown-fleshed) через поліфенольну реакцію. Плоди без насіння — вовнисто-жовті, ДУЖЕ в'яжучі.
- **Маса плоду:** 200–300 г.
- **Популярність:** Один із найпоширеніших сортів у Туреччині та Іспанії.
- **Умова врожаю:** Обов'язкове запилення сортом з рясним пилком (Госьо, Мізушима). Без запилення — тільки при штучному дозріванні.
</InfoBlock>

## 3.4. Нікітські гібридні сорти — Для Центральної України

Виведені у Нікітському ботанічному саду шляхом схрещування *D. kaki* × *D. virginiana* з метою підвищення морозостійкості та зниження в'яжучості.

<InfoBlock type="blue" icon="❄️" title="Нікітська Бордова (Nikitskaya Bordovaya)">
- **Тип:** PCA (потребує дозрівання).
- **Морозостійкість деревини:** До -25 °C (найстійкіший сорт!).
- **Маса плоду:** 120–180 г.
- **Цукристість після дозрівання:** 18–22° Brix.
- **Забарвлення:** Яскраво-бордово-червоне. Один із найдекоративніших сортів.
- **Рекомендований регіон:** Уся Центральна та Лісостепова Україна.
</InfoBlock>

<InfoBlock type="blue" icon="🏆" title="Перемога (Pobeditel / Nikitsky 8)">
- **Тип:** PCA/PVNA (перехідний тип — при наявності насіння майже їстівний).
- **Морозостійкість деревини:** До -23 °C.
- **Маса плоду:** 140–200 г.
- **Термін дозрівання:** Жовтень.
</InfoBlock>

## 3.5. Кавказькі та Середньоазійські сорти

<InfoBlock type="purple" icon="🌍" title="Хорьвалі (Horval / Груша хурма — Грузія)">
- **Тип:** PCA.
- **Форма плоду:** Грушоподібна (звідси — «хурма-груша»).
- **Маса плоду:** 80–120 г.
- **Особливість:** Характерний для Аджарії та Абхазії. Дуже поширена у Закарпатті.
- **Аромат:** Виразний, медово-карамельний після дозрівання.
</InfoBlock>
