<Callout type="important" title="Чашечка — найважливіша деталь при збиранні хурми">
Хурма є єдиною поширеною плодовою культурою, для якої збереженість чашечки (calyx) є критичним показником товарної якості. Плоди без чашечки або з пошкодженою чашечкою на холодильному ринку відносять до третього сорту або відбраковують. Вологи, що входить у м'якоть через відкриту без чашечки ранку, достатньо для розвитку Botrytis за 3–5 днів.
</Callout>

## 13.1. Визначення знімальної стиглості

### Для сортів PCNA (Їстівні з дерева):
- **Колір:** 80–90% сортового забарвлення.
- **Твердість:** 5–7 кг/см2 (пенетрометр).
- **Brix:** 14–18°.
- **Чашечка:** Зелена або жовтувато-зелена, міцно тримається.

### Для сортів PCA (з подальшим дозріванням):
- **Колір:** 70–80% забарвлення.
- **Твердість:** 7–10 кг/см2.
- **Ознака готовності до збору:** Чашечка починає підсихати і злегка відходить від плоду.

---

## 13.2. Техніка ручного збору

1. **Інструмент:** Секатор з прямими лезами або ножиці для збору плодів.
2. **Зріз:** Плодоніжку зрізають секатором на 1–2 см вище чашечки. Ніколи не відривають плід рукою — це пошкоджує чашечку та відкриває рану.
3. **Укладання:** Плоди укладають у дерев'яні лотки або пластикові контейнери без здавлювання, чашечкою догори.
4. **Транспортна тара:** Дерев'яні ящики або пластикові ящики на 6–8 кг, вистелені папером.

---

## 13.3. Параметри холодильного зберігання

| Параметр | Значення |
| :--- | :--- |
| **Температура** | 0...+0,5 °C |
| **Відносна вологість** | 85–90% |
| **CO2-концентрація (модиф. атмосфера)** | 5–8% |
| **Термін зберігання (PCNA, стандарт)** | 60–90 діб |
| **Термін зберігання (PCA, технічна стиглість)** | 90–120 діб |

---

## 13.4. MAP-зберігання хурми

Хурма чудово підходить для MAP-зберігання (Modified Atmosphere Packaging):
- **Матеріал пакета:** Поліетиленові пакети XTEND® або мікроперфоровані.
- **Склад атмосфери:** 2–4% O2 / 5–8% CO2.
- **Ефект CO2:** Зупиняє активність ферменту фенілаланінаміаклійази (PAL), знижує синтез нових фенольних сполук. Це УПОВІЛЬНЮЄ процес природного дозрівання PCA-сортів і подовжує термін зберігання.
