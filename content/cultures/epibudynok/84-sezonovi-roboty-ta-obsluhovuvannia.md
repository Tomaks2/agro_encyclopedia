Епібудинок — це не просто «кімната з вуликами». Це жива система, де працюють одночасно бджоли та люди. Обслуговування має враховувати обидва.

## 84.1. Сезонний цикл (Полтавщина)

| Місяць | Етап | Ключові дії |
|---|---|---|
| **Березень** | Передсезонна підготовка | Огляд конструкції після зими, перевірка сіток, ремонт покрівлі, підготовка вуликів до переселення |
| **Квітень** | Весняний запуск | Переселення сильних сімей у вулики епідоміку, запуск лежанки (1–2 сеанси на тиждень для адаптації), моніторинг бджіл |
| **Травень** | Активна експлуатація | Щоденні сеанси, контроль температури, вентилювання, огляд сімей раз на 7–10 днів |
| **Червень** | Пік сезону | Опівдні — найсильніше гудіння (найефективніший час для сеансів), контроль вентиляції, підтримка чистоти |
| **Липень** | Пік сезону | Те саме; додатково: полив вуликів (якщо спека >35 °C), тінь на дах (якщо перегрів) |
| **Серпень** | Пік сезону → початок спаду | Продовження сеансів; підготовка до осінньої годівлі |
| **Вересень** | Завершення сезону | Останні сеанси; осіння ревізія сімей, лікування вароатозу, підготовка до зимівлі |
| **Жовтень** | Консервація | Вилучення вуликів з епідоміку (або утеплення), прибирання лежанки, консервант деревини |
| **Листопад–Лютий** | Зимовий простій | Епібудинок НЕ використовується (або як звичайний сарай); вулики зимують окремо (на пасіці) |

## 84.2. Щоденні перевірки (у сезон)

1. **Температура людської зони**: 20–22 °C. Якщо >25 °C — відкрити вікно.
2. **Температура вуликів**: 33–37 °C у гнізді. Якщо >40 °C — тінь на дах, додаткове вентилювання.
3. **Льотки**: чи вільний виліт/заліт бджіл. Чи немає мертвих бджіл біля льотків.
4. **Чистота лежанки**: прибирання пилу, бджолиних решток (якщо є), свіже простирадло.
5. **Запах**: має бути медово-восковий. Якщо з'явився кислий/гнильний запах — оглянути сім'ю (можливо, гнилець).

## 84.3. Щотижневі перевірки

1. **Огляд сімей** (раз на 7–10 днів): відкрити вулик, перевірити розплід, корми, наявність матки, ознаки хвороб.
2. **Вентиляція**: очистити коникову щілину від пилу/павутини, перевірити клапан Ø150 мм.
3. **Сітки**: оглянути тамбур-сітку та віконні — чи немає розривів, чи не застрягли бджоли.
4. **Лежак**: перевірити перфорацію — чи не забилася бджолиним воском/прополісом. Очистити за потреби.

## 84.4. Щомісячні перевірки

1. **Покрівля**: оглянути м'яку черепицю — чи немає здуттів, тріщин, відшарувань.
2. **Стіни**: оглянути обшивку — чи немає щілин, через які можуть проникнути миші/оси.
3. **Електрика** (якщо є): перевірити розетки, вимикачі, освітлення.
4. **Запаси меду**: якщо сім'ї збирають надлишок — відкачати.
5. **Лежак + матрац**: прання простирадла, перевірка матраца на запах (якщо ввібрав — замінити).

## 84.5. Весняний запуск (детально)

1. **За 2 тижні до переселення**: оглянути епібудинок після зими, відремонтувати покрівлю, сітки, лежак.
2. **За 3 дні**: відкрити вікна для провітрювання (якщо закривали на зиму), прибрати лежак.
3. **День переселення**: перенести вулики з зимівника/пасіки в епібудинок. Ввечері (щоб бджоли не тривожилися днем).
4. **Перші 3 дні**: спостереження за поведінкою сімей — чи орієнтуються, чи не блукають між вуликами.
5. **Перший тиждень**: не використовувати лежанку — дати бджолам адаптуватися до нового приміщення.
6. **З 2-го тижня**: почати сеанси (1–2 на тиждень), поступово збільшувати до щоденних.

## 84.6. Осіння консервація (детально)

1. **Вересень**: провести ревізію сімей (сила, розплід, корми, матка). Визначити, які сім'ї зимують у епідоміку, які — на пасіці.
2. **Жовтень**:
   - Якщо вулики залишаються в епідоміку: утеплити (підкладач під дно, утеплювач на стелю вуликової зони), залишити тільки сильні сім'ї.
   - Якщо вулики переносяться: вилучити, закрити льотки сіткою, перенести на зимівник/пасіку.
3. **Прибирання лежанки**: прання простирадла, чистка матраца (або заміна), обробка деревини лежанки антисептиком (без запаху).
4. **Консервація деревини**: зовнішня обробка антисептиком (якщо потрібно), перевірка покрівлі.
5. **Закриття вікон**: москітні сітки залишити (захист від мишей), вікна закрити зсередини фанерою (якщо зимівник холодний).
6. **Дезінфекція**: обробити внутрішні поверхні розчином перекису водню 3 % (без запаху, безпечно для наступного сезону).

## 84.7. Зимовий простій

- Епібудинок НЕ використовується для сеансів узимку.
- Вулики або зимують у ньому (якщо утеплені), або переносяться на пасіку.
- Приміщення можна використовувати як сарай для інвентарю (але не зберігати хімікати!).
- Раз на місяць: оглянути приміщення — чи немає гризунів, протікань, конденсату.

## 84.8. Типові проблеми та вирішення

| Проблема | Причина | Вирішення |
|---|---|---|
| Перегрів вуликів (>40 °C) | Спека + слабка вентиляція | Тінь на дах, додаткове вентилювання, полив даху ввечері |
| Бджоли блукають між вуликами | Льотки занадто близько | Перемістити вулики (відстань ≥500 мм), додати орієнтири на кожен вулик |
| Забиття перфорації лежанка воском | Бджоли замазують щілини прополісом | Періодичне очищення (раз на 2 тижні), можна покрити лежак тонким листом нержавіючої сітки |
| Миші в епідоміку | Осінь, пошук тепла | Сітки ≤5 мм на всі отвори, ультразвукові відлякувачі, пастки |
| Конденсат на стінах | Різниця температур + слабка вентиляція | Посилити вентиляцію, додати пароізоляцію зсередині |
| Запах сечі (бджоли виносять екскременти) | Слабкий обліт | Посилити вентиляцію, частіше відкривати вікна |

## Підсумок

Сезон епідоміку: квітень–вересень. Весняний запуск — переселення сильних сімей, адаптація 1 тиждень, потім поступове введення сеансів. Літо — щоденні перевірки (температура, чистота, вентиляція), тижневі огляди сімей. Вересень — ревізія + лікування вароатозу. Жовтень — консервація (вилучення або утеплення вуликів, прибирання лежанки, антисептик). Зима — простій, щомісячний огляд.
