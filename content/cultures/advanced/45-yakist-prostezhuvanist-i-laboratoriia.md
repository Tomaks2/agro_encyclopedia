Якість продукту починається до відкачки. Вона залежить від здоров’я сімей, кормової ситуації, часу відбору, чистоти обладнання, тари, води, температури зберігання, записів та чесного маркування. Колір, аромат і кристалізація важливі для споживача, але самі по собі не встановлюють склад, ботанічне походження або відсутність домішок.

| Елемент партійного паспорта | Навіщо потрібен |
|---|---|
| Номер партії | Пов’язує продукт із датою й джерелом |
| Дата та місце відкачки | База простежуваності |
| Тип продукту і тара | Контроль зберігання й маркування |
| Дані про сім’ї / точку | Допомагають знайти першоджерело проблеми |
| Результати лабораторії | Відокремлюють виміряні показники від припущень |
| Умови зберігання | Важливі для стабільності продукту |
| Канал реалізації | Допомагає виконати відповідні вимоги |

## 45.1. Ключові лабораторні показники меду (ДСТУ 4497)

| Показник | Норма (ДСТУ 4497) | Метод аналізу |
|---|---|---|
| **Вологість** | ≤19-20% | Рефрактометр |
| **Діастазне число** | ≥5-7 одиниць | Ферментативний метод |
| **Вміст фруктози+глюкози** | ≥60% | HPLC або ензиматичний |
| **HMF** | ≤25 мг/кг (свіжий), ≤40 (експорт) | HPLC |
| **Активність інвертази** | ≥5-8 U/g | Ферментативний |
| **Електропровідність** | Залежить від сорту | Кондуктометрія |
| **Кислотність** | ≤40 мекв/кг | Титрування |
| **Пилок (мелісопалінологія)** | Ідентифікація ботанічного походження | Мікроскопія |

## 45.2. Методи виявлення фальсифікації

| Метод | Що виявляє | Точність |
|---|---|---|
| **NMR (ядерний магнітний резонанс)** | Повний профіль цукрів, географічне походження | Висока (золотий стандарт) |
| **IRMS (ізотопний аналіз)** | C4-цукри (кукурудзяний сироп) через δ13C | Висока |
| **LC-MS/MS** | Антибіотики, пестициди | Висока |
| **GC-MS** | Ароматичний профіль, ботанічне походження | Висока |
| **HPLC** | Фруктоза/глюкоза/сахароза/HMF | Середня-висока |
| **Тест Клейна (якісний)** | Груба фальсифікація цукром | Низька (тільки скринінг) |

**Практичне**: NMR-аналіз коштує 150-300 євро за зразок. Для домашнього пасічника достатньо: вологість (рефрактометр, 500 грн) + діастазне число (лабораторія, 300-500 грн).

## 45.3. Покрокова простежуваність: від вулика до баночки

```
1. Вулик №07 → медозбір акація 25.05-05.06
2. Відкачка 08.06 → партія A-2026-01
3. Фільтрація → відстій 2 дні
4. Розлив у тару (банка 500 мл) → етикетка: партія A-2026-01
5. Лабораторний аналіз (за бажанням) → протокол №1234
6. Продаж → запис: дата, покупець (оптом) або ринок (роздріб)
```

**Мінімальний набір записів**: № партії | дата відкачки | медонос | № вуликів | вага | лабораторія (якщо є).

## 45.4. Сертифікація та експорт

| Документ | Для чого | Хто видає |
|---|---|---|
| **Декларація відповідності ДСТУ** | Продаж в Україні | Пасічник (самодекларація) |
| **Протокол лабораторії** | Підтвердження якості | Акредитована лабораторія |
| **Ветеринарний сертифікат** | Експорт в ЄС | Держпродспоживслужба |
| **EU Honey Directive (2001/110/EC)** | Вимоги ЄС | Європейська комісія |
| **Codex Alimentarius (CXS 12-1981)** | Міжнародні стандарти | FAO/WHO |

**Експорт в ЄС**: потрібен ветеринарний сертифікат + лабораторний протокол (HMF, діастаза, вологість, антибіотики).

Лабораторний аналіз не потрібен для кожної баночки домашнього меду, але необхідний там, де заявляється конкретна відповідність стандарту, ботанічне походження, експортна якість або коли виникла підозра на проблему. Відповідальна комунікація звучить так: «для партії доступний такий-то аналіз», а не «ми знаємо, що мед чистий, бо він наш».

## Підсумок

Простежуваність — це не бюрократія, а довіра. Вона захищає пасічника, покупця і репутацію продукту, даючи змогу підтвердити факти записами й аналізами.
