Ця карта потрібна, щоб читач не плутав три різні речі: **продукт як їжу або сировину**, **продукт як об’єкт наукового дослідження** і **продукт як заявлений засіб лікування**. Перша й друга категорії можуть бути цінними; третя потребує конкретних клінічних доказів та професійної відповідальності.

| Продукт | Найбільш корисний фокус енциклопедії | Найважливіший ризик комунікації |
|---|---|---|
| Мед | Походження, зрілість, якість, простежуваність, харчова культура | Перетворити харчовий продукт на «ліки від усього» |
| Прополіс | Варіативність складу, стандартизація, реміснича технологія | Подати домашню настоянку як гарантовану терапію |
| Маточне молочко | Біологія виробництва, холодовий ланцюг, 10-HDA, якість | Гормональні й «імунні» обіцянки без достатніх даних |
| Пилок і перга | Ботанічне походження, сушіння, волога, алергени | Обіцянки лікування анемії або алергій |
| Гомогенат | Санітарія, заморожування, простежуваність | Анаболічні, репродуктивні та «чоловічі» твердження |
| Підмор | Походження, біобезпека, відмінність між сировиною та очищеним хітозаном | Настоянки як «сорбент» або лікування хвороб |
| Бджолина отрута | Токсикологія, алергія, клінічна безпека | Самостійні ужалення та терапевтичні схеми |

## 47.2. Детальна карта: продукт → докази → протипоказання

### Мед
| Аспект | Деталі |
|---|---|
| **Докази (рівень)** | Рани/опіки: 1a (Manuka); Кашель у дітей: 1b-2a; Шлункові виразки: 2b |
| **Механізм** | Осмотичний ефект + H2O2 (глюкозооксидаза) + низький pH |
| **Протипоказання** | Діабет (обережно), ботулізм у дітей &lt;1 року, алергія |
| **Безпечна доза** | 1-2 ст.л./день (здоровий дорослий) |

### Прополіс
| Аспект | Деталі |
|---|---|
| **Докази (рівень)** | Афтозний стоматит: 1b; Герпес: 1b-2a; Зубний наліт: 2b |
| **Механізм** | Флавоноїди (піноцембрин, хризин) → антимікробна + протизапальна діja |
| **Протипоказання** | Алергія на бджолині продукти, астма (рідко) |
| **Безпечна доза** | 300-500 мг екстракту/день (стандартизований) |

### Маточне молочко
| Аспект | Деталі |
|---|---|
| **Докази (рівень)** | Холестерин: 2a; Загоєння ран: 2b; menopausa: 3a |
| **Механізм** | 10-HDA → anti-inflammatory; Royalactin → клітинна проліферація |
| **Протипоказання** | Алергія (анафілаксія можлива!), астма |
| **Безпечна доза** | 500-1000 мг/день (свіжий), зберігати при -18°C |

### Пилок та перга
| Аспект | Деталі |
|---|---|
| **Докази (рівень)** | Антиоксидант: 2b; Витривалість: 3b; Анемія: 4 |
| **Механізм** | Флавоноїди (рутин, кверцетин) + білки (20-30%) + вітаміни |
| **Протипоказання** | Поліноз (алергія на пилок), алергія |
| **Безпечна доза** | 5-15 г/день (пилок), 10-20 г/день (перга) |

### Гомогенат трутневий
| Аспект | Деталі |
|---|---|
| **Докази (рівень)** | Адаптоген: 3b-4; Тестостерон: 4 (слабкі дані) |
| **Механізм** | Ектісони + IGF-1-подібні → анаболічний ефект |
| **Протипоказання** | Гормонозалежні пухлини, алергія |
| **Безпечна доза** | 1-2 ч.л./день (свіжий, заморожений) |

### Підмор
| Аспект | Деталі |
|---|---|
| **Докази (рівень)** | Хітозан: 2b (як ізольована речовина); Настоянка: 5 |
| **Механізм** | Хітозан → сорбент, гепатотропна дія |
| **Протипоказання** | Алергія на хітин, ниркова недостатність |
| **Безпечна доза** | Настоянка: 15-20 крапель 2 р/день |

### Бджолина отрута
| Аспект | Деталі |
|---|---|
| **Докази (рівень)** | РС (розсіяний склероз): 1b (негативний результат РСТ); Артрит: 2b-3a |
| **Механізм** | Мелітін → anti-inflammatory; Апамін → нейропротекція |
| **Протипоказання** | Алергія на ужалення (абсолютна!), вагітність, нирки |
| **Безпечна доза** | Тільки під наглядом спеціаліста |

## 47.3. Практичне правило

Якщо твердження пов’язане зі зміною перебігу хвороби, симптомом, дозою, курсом, дитиною, вагітністю, онкологією, алергією, ужаленням або відміною ліків — воно не може бути подано без чіткого рівня доказовості, джерела і застереження. Якщо твердження описує продукт, традицію, технологію чи смак — його можна подавати як ремісничу й культурну інформацію, не створюючи хибної медичної обіцянки.

## Підсумок

Найсильніший матеріал про продукти бджільництва не зменшує їхню цінність, а робить її зрозумілою: продукт має походження, технологію, якість, ризики й реальні межі даних. Саме ця чесність створює довіру.
