1. **Суперранні та Ранні гібриди:** Вегетація 45–65 днів від висадки розсади. Пухкі ніжні качани масою 1,0–2,0 кг для свіжих літніх салатів (Парель F1, Дитмарська, Миррор F1). Не придатні для засолювання та зберігання!
2. **Середньопізні засолювальні гібриди:** Вегетація 110–120 днів. Щільні великі качани масою **3,5–5,0 кг** із високим вмістом цукрів (Агресор F1, Глоб F1, Атрія F1). Еталон для квашення.
3. **Пізньостиглі зимові гібриди:** Вегетація 130–140 днів. Найдрібніші качани з товстим восковим нальотом для тривалого зберігання до травня (Блоктор F1, Леннокс F1).
</Callout>

## 2.1. Детальний аналіз провідних гібридів F1

<InfoBlock type="gold" icon="👑" title="1. Агресор F1 (Agressor F1) — Syngenta (Швейцарія)">
- **Призначення:** Світовий номер 1 для засолювання, квашення та середнього зберігання.
- **Термін:** 110–120 днів від висадки.
- **Качан:** Округло-плескатий, масою **3,5–5,0 кг**, не розтріскується.
- **Стійкість:** Імунний до трипсів та фузаріозного в'янення!

</InfoBlock>

<InfoBlock type="gold" icon="🥇" title="2. Парель F1 (Parel F1) — Bejo">
- **Особливість:** Суперранній партенокарпічний білок (45–50 днів).
- **Качан:** Округлий, масою **1,0–1,5 кг**, ніжний соковитий смак.
</InfoBlock>
