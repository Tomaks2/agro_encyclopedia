# 18. 15 міфів про сливу

Найпоширеніші хибні уявлення про сливу — від «невибагливої культури» до очікувань щодо самоплідності та зберігання — коштують садівникам роки втраченого врожаю. Кожен міф нижче розібрано за фактами з наукових джерел.

### 📌 СХЕМА 124: МІФИ ПРО БОТАНІКУ ТА ВИРОЩУВАННЯ

| Міф | Реальність |
| :--- | :--- |
| «Слива — невибаглива культура, росте сама» | Слива найменш толерантна з кісточкових до неправильної агротехніки: перевантаження урожаю вбиває дерево за 3–4 роки |
| «Всі сливи однакові, достатньо знати назву сорту» | Угорка, ренклод, диплоїд і алича — різні біологічні сценарії з різною плодоносною деревиною |
| «Чим більше цвіту — тим більше врожаю» | Без запилювача або в дощове цвітіння море квіток дає нуль плодів; цвітіння — індикатор, а не гарантія |
| «Слива витримує будь-який ґрунт» | Застій води >48 годин на важких ґрунтах = задушення коренів і цитоспороз;дренаж потрібен навіть аличі |
| «Обрізати сливу можна навесні, як яблуню» | Весняна обрізка — ворота для бактеріального раку (Pseudomonas); основний обсяг — літні зелені операції |

### 📌 СХЕМА 125: МІФИ ПРО ЗАХИСТ ТА ЗБЕРІГАННЯ

| Міф | Реальність |
| :--- | :--- |
| «Вишнева муха пошкоджує тільки вишню» | Сливова плодожерка — головний «червивий» шкідник саме сливи; обробка в червні–серпні обов'язкова |
| «Шарку (віспу) можна вилікувати обприскуванням» | PPV не лікується хімією: діагностика ELISA/ПЛР → вирубка → карантин 3–5 років |
| «Моніліоз зникає після обрізки мумій» | Без обробок у два вікна (рожевий бутон + опадення пелюсток) обрізка знижує фон лише на 20–30% |
| «Слива добре зберігається в холодильнику місяцями» | Ранні сорти не зберігаються взагалі; пізні (Stanley, Angeleno) — максимум 3–6 тижнів при 0…+1°C |
| «Для чорносливу годиться будь-яка слива» | EU-стандарт вимагає Brix ≥20° у сировині: тільки Stanley, Чачакска, Presley дають кондиційний продукт |
| «Зимостійка слива не вимерзне ніколи» | Квіткові бруньки Угорки після зимової відлиги гинуть при -18…-20°C; ризик — саме коливання температур |
| «Самоплідний сорт не потребує запилювача» | Без запилювача самоплідні сорти дають 30–60% потенціалу; з сумісним сортом — до 100% |

> 📌 **Головний підсумок розділу:** слива пробачає менше помилок, ніж здається на перший погляд. Успіх дають чотири речі: правильна група (угорка/ренклод/диплоїд/алича) під ваш ґрунт і клімат, запилювач для кожного сорту, літня замість весняної обрізки та два вікна захисту від моніліозу.
