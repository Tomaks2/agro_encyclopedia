<Callout type="important" title="Генетичні типи солодощі цукрової кукурудзи">
Цукрова кукурудза (*Zea mays* var. *saccharata* Sturt.) відрізняється від зернової кормової наявністю природних мутантних генів, які блокують конверсію (перетворення) водорозчинних цукрів у крохмаль під час дозрівання зернівки.
- **Стандартні цукрові (SU / Su1 — Standard Sweet):** Вміст цукру **5–10%**. Після збору цукор швидко перетворюється на крохмаль за 12–24 години.
- **Поліпшені цукрові (SE / Se1 — Sugar Enhanced):** Вміст цукру **12–18%**. Зерно має ніжнішу оболонку.
- **Надсолодкі (SH2 / Sh2 — Super Sweet):** Вміст цукру **25–40%**! Конверсія в крохмаль уповільнена у 6 разів — зерно залишається солодким протягом 7–10 днів після збору.
</Callout>

## 1.1. Морфологія однодомної рослини

```
                     Анатомія рослини цукрової кукурудзи
  
                        [ Чоловіче суцвіття - Волоть ]
                           (Продукування пилку)
                                    │
                                    ▼ (Запилення вітром)
                        ┌────────────────────────┐
                        │ Жіноче суцвіття - Качан│
                        │ (Приймочки - «шовк»)   │
                        └───────────┬────────────┘
                                    │
                                   ─┴─ [Опорні корені]
```

1. **Волоть (Чоловіче суцвіття):** Розташована на верхівці стебла, продукує до **20–25 мільйонів пилкових зерен**.
2. **Качан (Жіноче суцвіття):** Розташований у пазухах листя у середній частині стебла. З кожної неоплодотвореної зернівки виходить довга ниткоподібна маточка — **«шовк» (silk)**. Для повного виповнення качана кожен «шовк» повинен отримати пилкове зерно.

## 1.2. Шкала фенологічних фаз BBCH для цукрової кукурудзи

| Код BBCH | Фаза розвитку | Агротехніка |
| :--- | :--- | :--- |
| **BBCH 00–09** | Висів насіння та поява сходів | Висів при t ґрунту **> +12...+14 °C** (для SH2). |
| **BBCH 13–19** | 3–9 листків (Формування генеративних органів)| **Критична фаза №1:** Позакореневе внесення Цинку (Zn). |
| **BBCH 51–59** | Викидання волоті | Початок інтенсивного крапельного зрошення. |
| **BBCH 61–65** | Цвітіння (Вихід нитей маточки / «шовку») | **Критична фаза №2:** Захист від стеблового метелика та совок. |
| **BBCH 71–75** | Молочна стиглість (Вологість зерна 70–72%) | **ЗБІР УРОЖАЮ!** Ніжне соковите зерно, виділення «молока». |
