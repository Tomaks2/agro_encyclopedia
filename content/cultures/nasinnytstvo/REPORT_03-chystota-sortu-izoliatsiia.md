# Звіт перевірених тверджень: глава 03

## Статус

Глава підготовлена як перша робоча глава спільної бази «Насінництво й селекція». Джерела відкрито й прочитано в цій сесії. Числові значення подано лише з контекстом джерела та без перенесення на українські норми.

## C — розбіжності джерел

- Значення ізоляції для кукурудзи: NMSU наводить 2 милі, MSU — 5 200 футів для цукрової кукурудзи. Їх не усереднено.
- Значення для гарбузових: NMSU наводить 0,5 милі для *Cucurbita pepo*, MSU — 1 300 футів для squash. У тексті зазначено різний контекст і неможливість перенесення як універсальної норми.

## CAVEAT

- Чинні українські нормативні значення для сортової чистоти та ізоляції не включено до глави: сторінка zakon.rada.gov.ua, знайдена під час пошуку, не віддала читабельний текст у цій сесії. Потрібна ручна перевірка офіційного першоджерела перед будь-яким юридичним або нормативним формулюванням.
- Джерела NMSU, MSU та Seed Savers Exchange — американські/міжнародні або професійні матеріали. Їхні відстані не подано як українські стандарти.

## U — непідтверджене й не включене

- Універсальна «безпечна» відстань для кожної культури.
- Гарантована сортова чистота після ізоляції.
- Конкретна мінімальна кількість рослин для всіх культур.
- Частка перезапилення томата в умовах України.

## Редакційні елементи

- Порада вести карту джерел пилку, журнал цвітіння та маркування партій — редакційна рекомендація для простежуваності, а не агрономічна норма.
- Окремо зазначати вид гарбузових — редакційна рекомендація, що запобігає змішанню побутових назв із видовою сумісністю.

## Тест на вигадування: 5 тверджень

Повторно звірено з відкритими сторінками після написання:

1. Різниця між впливом пилку на плід поточного сезону та потомство — MSU, розділ про pepper.
2. Приклади 2 милі та 0,5 милі — NMSU, Preserving Variety Integrity / Distance.
3. 5 200 футів для цукрової кукурудзи — MSU, Table 1.
4. Заборона пластикових і паперових пакетів для квіток — NMSU, Physical barriers.
5. Неможливість покладатися на фізичну ізоляцію для вітрозапильних культур — Seed Savers Exchange, Isolation Methods.
