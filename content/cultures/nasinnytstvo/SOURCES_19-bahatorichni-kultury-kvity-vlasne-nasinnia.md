# Джерела 19: багаторічні культури та квіти — власне насіння

## Джерельна карта

| Джерело | Що підтверджує в главі |
| :--- | :--- |
| [1] NC State Extension | Відмінність статевого й нестатевого розмноження; клонування живцями, поділом, відсадками, щепленням і мікророзмноженням; базова логіка спокою насіння |
| [2] University of Missouri Extension | Вегетативне розмноження як створення генетично ідентичного клону; поділ багаторічних рослин |
| [3] UF/IFAS | Само- та перехресне запилення; OP проти F1; ізоляція з урахуванням виду, сорту, запилювачів і ділянки; насіннєва стиглість квітів і сухих плодів |
| [4] Oregon State University Extension, EM 9663 | Вибір OP, наслідки насіння F1; здорові маточні рослини; зріла оболонка; сухе очищення, провіювання, сушіння, маркування і зберігання |
| [5] Oregon State University Extension, Collecting and Storing Seeds | Дворічні цибуля й капустяні; квіткові коробочки, кошики та головки; збір сухих частин; тест схожості й умови зберігання |
| [6] eOrganic / Washington State University | Насіннєві патогени; профілактика; межі гарячої води й хімічних обробок; ризик втрати схожості та необхідність здорового насіння |
| [7] Iowa State University Extension | Сухе прохолодне зберігання; герметична тара; паперовий тест схожості; обмеження побутового дегідратора |
| [8] Penn State Extension | Індивідуальні вимоги насіння; фізіологічний спокій; холодна волога стратифікація як конкретний спосіб для частини насіння |
| [9] University of Minnesota Extension | Холодний вологий період для багатьох місцевих багаторічників; застереження рахувати видоспецифічний період, а не застосовувати універсальний строк |

## Що не переносилося між культурами

- Відстані ізоляції не узагальнювалися: UF/IFAS прямо пов’язує їх із видом, сортом, пилком, запилювачами та місцевістю.
- Стратифікація не задана як обов’язкова для всіх багаторічників: Penn State й UMN описують її лише для частини насіння та наголошують на індивідуальних вимогах.
- Температури сушіння з джерел не перетворені на домашній режим. Згадана OSU межа нагрівання — застереження проти перегріву, а не універсальна температура сушіння.
- Таблиці тривалості зберігання овочів не перенесені на квіти, спаржу, часник, цибулю чи суницю без окремого джерела.
- Локальні профілі використано для контексту органів відновлення та способів розмноження; вони не замінюють видоспецифічний насінницький регламент.
