<Callout type="important" title="Абрикос — клімактеричний плід">
На відміну від черешні, абрикос є клімактеричним плодом — він продовжує дозрівати після знімання з дерева, виробляючи етилен. Це дозволяє збирати плоди у стані «технічної стиглості» (70–80% забарвлення) для тривалого зберігання та транспортування, але вимагає дотримання холодового ланцюга для запобігання надмірному дозріванню.
</Callout>

## 15.1. Критерії визначення стиглості

### 1. Забарвлення шкірки:
- Для свіжого ринку (відвантаження у той самий день): **85–95% сортового забарвлення**, м'якоть злегка піддається натисканню.
- Для відправки на відстань до 500 км: **60–70% забарвлення**, м'якоть тверда.
- Для переробки (консерви, соки): **100% стиглість**, повна відповідність кольору та аромату.

### 2. Рефрактометрія (°Brix):
- Мінімальний поріг збору для свіжого ринку: **12–14° Brix**.
- Оптимальна споживча стиглість: **16–20° Brix** (залежно від сорту).

### 3. Твердість м'якоті (Пенетрометр):
- При 6–8 кг/см2 — технічна стиглість (для транспортування).
- При 3–4 кг/см2 — споживча стиглість.

---

## 15.2. Техніка ручного збору

- Збирають у суху погоду, в ранкові години (6:00–11:00), поки плоди не нагрілися.
- Плід беруть усією долонею і злегка повертають убік — рухом відриву від плодоніжки. Ніколи не тягнуть вниз — це обриває плодоніжку і пошкоджує місце кріплення наступного плоду.
- Тара: Ящики місткістю **4–5 кг**, вистелені поролоном.
- Укладати плоди «щічкою» донизу (частиною без рум'янця) для зменшення механічних пошкоджень при транспортуванні.

---

## 15.3. Параметри холодильного зберігання

| Параметр | Значення |
| :--- | :--- |
| **Температура** | +0,5...+1,5 °C |
| **Відносна вологість** | 90–95% |
| **Термін зберігання (стандарт)** | 3–4 тижні (при 70% забарвленні на момент збору) |
| **Термін у MAP (модиф. атмосфера)** | до 6–8 тижнів |

### MAP-параметри для абрикоса:
- O2: 2–3%.
- CO2: 5–8%.
- Пакети: Xtend® або LifeSpan® мембранні пакети.
