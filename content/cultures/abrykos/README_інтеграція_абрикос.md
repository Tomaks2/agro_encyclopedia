# Абрикос — комплект для інтеграції

Цей архів містить повний оновлений комплект культури **Абрикос** для сайту agro-encyclopedia. Загальна структура відповідає еталону (яблуня → груша → персик): 19 розділів із замкненим NextChapter-ланцюгом, 27 СХЕМ, клікабельні джерела, підсумки розділів та окремий файл з готовими промптами для генерації інфографік.

## Що зроблено в цьому комплекті

**Поглиблення 17 існуючих розділів.** Додано 25 СХЕМ (наскрізна нумерація 1–27, без пропусків і дублів) у ключові підрозділи: біологія та фенологія (BBCH, chilling hours), підщепи, сорти, формування, обрізка, живлення, полив, хвороби, шкідники, календар захисту, щеплення, збір та курага. NextChapter-ланцюг уніфіковано до формату `chapterNum="N"` і замкнено: `01→02→…→17→18→19→01`. У кожен файл додано блок «## Джерела» з клікабельними URL (47 посилань на Penn State, UC Davis, UC ANR, MSU, WSU, НААН, АгроТайм) та «📌 Головний підсумок розділу».

**Два нових розділи.** `18-mify.md` — 15 найпоширеніших міфів про абрикос з розвінчанням і перенаправленнями на розділи-розвінчувачі (СХЕМА 27 — шпаргалка «міф → реальність»). `19-zamorozky.md` — система захисту від весняних заморозків: критичні температури по фенофазах BBCH за даними Penn State/WSU EBO419 та Michigan State, моніторинг, пасивний/активний захист, покроковий алгоритм у ніч заморозку (СХЕМА 26).

## Як інтегрувати (3 кроки)

**Крок 1. Файли контенту.** Видаліть у репозиторії старі 17 MD-файлів абрикоса та старий `meta.json` з `content/cultures/abrykos/` і замість них покладіть 19 нових MD-файлів та новий `meta.json` з цього архіву.

**Крок 2. Фото НЕ потрібні.** Нові розділи (18, 19) використовують існуючі hero-фото з `public/images/cultures/abrykos/` — нічого завантажувати не треба.

**Крок 3. Інфографіки (опціонально, пізніше).** Файл `GENERATION_PROMPTS.md` містить 12 детальних промптів для генерації AI-інфографік. Коли картинки будуть згенеровані (вашими інструментами або Manus після відновлення ліміту), повідомте Manus список файлів — він вставить LightboxImage у відповідні MD-файли та видалить промпт з цього файлу.

## Перевірки, виконані перед передачею

NextChapter-ланцюг цілісний (01→19→01), filename↔slug у meta.json збігаються для всіх 19 секцій, нумерація СХЕМ 1–27 без дублів, порядок фінальних блоків у кожному файлі: контент → підсумок → джерела → NextChapter, hero-фото без дублів.
