## 9.1. Захисне спорядження

### Костюм (комбінезон або куртка з сіткою)

Білий або світлий колір — бджоли атакують темне (асоціація з ведмедем/борсуком). Матеріал — бавовна або змішана тканина, не синтетика (через синтетику жало проникає легше). Сітка на каптурі — дрібна, не метал (метал нагрівається на сонці).

### Рукавички

Шкіряні або з товстої тканини. Новачку — обов'язково; досвідченому — за бажанням (голі руки краще відчувають рамку, менше шансів придавити бджолу).

### Накурювач (димар)

Класичний димар: циліндр + міхи + камера для палива. Паливо: суха трава, тирса, сухе листя, картон. **Не використовувати**: синтетичні матеріали, гуму, пластик — токсичний дим отруює бджіл.

Принцип: дим маскує тривожний феромон (ізоамілацетат) і імітує лісову пожежу — бджоли заповнюють зоби медом і стають спокійними.

### Стамеска пасічна

Металева лопатка з вигином — для розділення рамок, зскрібання прополісу, підняття кришок. Обов'язковий інструмент: бджоли склеюють все прополісом, без стамески не відкрити.

### Щітка пасічна

М'яка щітка для зметання бджіл з рамок при відборі меду. Не давити бджіл рукою — злить сім'ю.

## 9.2. Медогонка

### Типи медогонок

**Радіальна** (рамки стоять радіусом, як спиці колеса): вміщує 4–20 рамок, відкачка одночасно з обох боків, висока швидкість, менше пошкоджень стільника. **Оптимум для дому**: радіальна на 4–8 рамок (ручна або електро).

**Хордіальна** (рамки паралельно хорді барабана): вміщує 2–6 рамок, відкачка по черзі з кожного боку (перевертати рамки), повільніша, але дешевша. Для 2–5 вуликів — достатньо.

**Напіврадіальна** (гібрид): рамки під кутом, відкачка з обох боків без перевертання, але вміст менший за радіальну.

### Матеріал

Нержавіюча сталь (нержавійка) — стандарт. Алюміній — дешевше, але гірше миється, окислюється. Пластик — тільки для домашнього використання, не професійного.

### Привід

Ручний (дешевше, менше 10 вуликів) vs електро (швидше, для 10+ вуликів). Для дому з 2–5 вуликами — ручна радіальна на 4 рамки — оптимум.

## 9.3. Воскотопка та переробка wax

**Сонячна воскотопка**: ящик зі скляною кришкою, сонце плавіть wax. Економна, але повільна (тільки сонячна погода).

**Парова воскотопка**: бак з водою, нагрів, wax спливає. Швидка, для будь-якої погоди. Для 5–20 вуликів — парова на 10–20 л.

**Електро воскотопка**: теновий нагрів, контроль температури. Для великих пасік.

## 9.4. Інші обов'язкові інструменти

| Інструмент | Призначення |
|---|---|
| Рефрактометр | Вимірювання вологості меду (норма < 20%) |
| Ваги вуликові | Контроль медозбору без відкриття вулика |
| Термометр вуликовий | Контроль температури гнізда |
| Годівниця | Підкормка сиропом (зверху або збоку) |
| Маткова клітка | Підсадка нової матки |
| Матковий ковпачок | Ізоляція матки на рамці |
| Рамковий тримач | Перенесення рамок |
| Ємності для меду | Нержавійка або пластик харчовий, 10–50 л |
| Фільтр меду | Сітка 0,3–0,5 мм для очищення |
| Ножі для зрізу кришечок | Електро або звичайний з зубцями |

## 9.7. Вибір та догляд медогонки

**Як обрати медогонку**:
- **До 5 вуликів**: радіальна ручна на 4 рамки (300–500 грн/місяць медозбору) — оптимум
- **5–15 вуликів**: радіальна електро на 8 рамок — економить 2–3 години на відкачку
- **15+ вуликів**: радіальна електро на 12–16 рамок + нержавіючий бак

**Догляд за медогонкою**:
- Після відкачки — промити теплою водою (40–50°C), висушити
- Раз на сезон — змастити підшипник (солидол або силіконова мастило)
- Зберігати в сухому місці — нержавійка не іржавіє, але привід може окислюватися
- Перевіряти кріплення рамок — ослаблені гвинти = пошкодження стільника

**Поширені поломки та ремонт**:
- Привід не обертається — замінити підшипник (200–500 грн)
- Барабан хитається — затягнути кріплення або замінити вісь
- Протікає кран — замінити прокладку (50–100 грн)

## 9.8. Типові помилки вибору обладнання

| Помилка | Наслідок | Правильно |
|---|---|---|
| Купити дешеву хордіальну медогонку | Довга відкачка, пошкодження стільника | Радіальна на 4+ рамки |
| Костюм з синтетики | Жало проникає легше, потієш | Бавовна або змішана тканина |
| Димар з пластиком/гумою | Токсичний дим отруює бджіл | Тільки суха трава, тирса, картон |
| Не купити рефрактометр | Продаєш вологий мед (&lt;20%) | Рефрактометр — обов'язковий |
| Економити на стамесці | Не відкрити вулик без пошкодження | Купити якісну стамеску (нержавійка) |
| Пластикова медогонка | Окислення, запах, недовговічна | Нержавіюча сталь |
| Не мати запасних рамок | При розширенні — немає куди ставити | 20–30 запасних рамок з вощиною |
| Воскотопка без терморегулятора | Перегрів wax > 70°C = окислення | Тен з терморегулятором, макс 65°C |

## 9.9. Відкачка меду: покроковий алгоритм

**Підготовка**:
1. Відібрати рамки з медом (запечатані ≥ 2/3 комірки)
2. Зняти воскові кришечки ножем або електро-ножем (зрізати тонкий шар)
3. Поставити рамки в медогонку (баланс — навхрест для рівномірного обертання)

**Відкачка**:
4. Обертати повільно (30–40 об/хв) — 2–3 хвилини з першого боку
5. Перевернути рамки, обертати з другого боку
6. Злити мед через фільтр (сітка 0,3–0,5 мм) у ємність
7. Перевірити вологість рефрактометром — норма < 20%

**Після відкачки**:
8. Повернути рамки у вулик (бджоли оближуть залишки меду — економія wax)
9. Промити медогонку теплою водою
10. Мед — в темне прохолодне місце (10–15°C), не в холодильник (кристалізація прискорюється)

## 9.10. Зберігання інвентарю

**Правила зберігання**:
- Медогонка: сухе місце, підвішена або на підставці
- Димар: очистити від попелу, зберігати окремо (запах)
- Костюм: прати при 40°C, не відбілювати (хлор руйнує сітку)
- Стамеска/щітка: очистити від прополісу, зберігати в коробці
- Рамки з вощиною: вертикально, в сухому місці, захист від мишей (миші їдять вощину)
- Вощина: 18–25°C, не вище 30°C (плаиться)
- Ємності для меду: промиті, сухі, з щільною кришкою

## 9.6. Практичний підсумок

1. **Мінімум для старту (2–5 вуликів)**: медогонка радіальна 4 рамки (ручна), димар, костюм, стамеска, щітка, waxотопка парова, рефрактометр.
2. **Димар — паливо тільки натуральне**: суха трава, тирса, картон. Ніякого пластику чи гуми.
3. **Рефрактометр обов'язковий**: вологість меду < 20% — стандарт якості. Вище 21% — бродить.
4. **Білий костюм**: бджоли не атакують світле.
5. **Ваги вуликові** — найкращий інструмент для контролю медозбору без відкриття вулика.
