## 35.1. Зима (грудень-лютий)

### Грудень

1. **Контроль зимівлі**: прослуховування вуликів (слуховою трубкою) — рівномірний шум = норма.
2. **Сніг**: очистка льотків від снігу.
3. **Миші**: перевірка мишозахисних сіток.
4. **Планування**: закупівля інвентарю, рамок, вощини.

### Січень

1. **Контроль зимівлі**: прослуховування (1 раз/2 тижні).
2. **Сніг**: очистка льотків.
3. **Планування**: складання плану сезону (кочівля, медозбір, матки).

### Лютий

1. **Контроль зимівлі**: прослуховування.
2. **Приготування канди/сиропу**: для весняної підгодівлі.
3. **Ремонт інвентарю**: вулики, рамки, медогонки.
4. **Закупівля**: вощина, препарати для вароатозу.

## 35.2. Весна (березень-травень)

### Березень

1. **Перший обльот**: при +8-10°C (зазвичай березень-квітень, Полтавщина).
2. **Ревізія гнізда**: після обльоту — сила сім'ї, наявність матки, корми, підмор.
3. **Весняне скорочення**: прибрати зайві рамки.
4. **Утеплення**: залишити до стабільного потепління.
5. **Підгодівля**: рідкий сироп 1:1 або канди при недостачі кормів.
6. **Лікування нозематозу**: Фумагілін-B при виявленні.

### Квітень

1. **Розширення гнізда**: поступове (1 рамка/тиждень).
2. **Профілактика вароатозу**: сітчасте дно, моніторинг.
3. **Медоноси**: верба, клен, плодові (яблуня, груша), акація (кінець квітня-початок травня).
4. **Відводи**: формування відводків при загрозі роїння.
5. **Підсилення слабких сімей**: об'єднання або перестановка рамок з розплодом.

### Травень

1. **Активний медозбір**: акація (середина травня-початок червня, Полтавщина).
2. **Контроль роїння**: вирізання ройових маточників, додавання рамок з вощиною.
3. **Моніторинг вароатозу**: 1 раз/місяць.
4. **Кочівля**: до пізніх медоносів (гречка, соняшник) — підготовка вуликів.
5. **Матки**: заміна старих маток (при необхідності).

## 35.3. Літо (червень-серпень)

### Червень

1. **Медозбір**: акація (продовження), липа (кінець червня-початок липня).
2. **Відкачка меду**: перша відкачка (акація).
3. **Контроль роїння**: вирізання маточників, додавання магазинів.
4. **Моніторинг вароатозу**: 1 раз/місяць.
5. **Підгодівля стимулююча**: сироп 1:1 (при слабкому медозборі).

### Липень

1. **Медозбір**: липа (продовження), гречка (середина липня-серпень).
2. **Відкачка меду**: липовий мед.
3. **Лікування вароатозу**: після відкачки меду (обов'язково).
4. **Моніторинг вароатозу**: 1 раз/2 тижні (осінь наближається).
5. **Кочівля**: до гречки, соняшнику.

### Серпень

1. **Медозбір**: гречка (продовження), соняшник (середина серпня-вересень), золотушник (кінець серпня-жовтень).
2. **Відкачка меду**: гречаний, соняшниковий.
3. **Лікування вароатозу**: повторне (якщо перше недостатнє).
4. **Моніторинг вароатозу**: 1 раз/2 тижні.
5. **Підготовка до зимівлі**: формування кормових запасів (20-25 кг/сім'я).

## 35.4. Осінь (вересень-листопад)

### Вересень

1. **Медозбір**: соняшник (продовження), золотушник.
2. **Відкачка меду**: остання відкачка.
3. **Підгодівля**: цукровий сироп 2:1 (для заповнення зимових запасів).
4. **Лікування вароатозу**: осіннє (обов'язково до вересня).
5. **Скорочення гнізда**: прибрати зайві рамки (без бджіл, без меду, старі темні).
6. **Останній обльот**: при +10-12°C.

### Жовтень

1. **Останній обльот**: при +10-12°C (якщо не встигли у вересні).
2. **Утеплення**: подушка 10 см зверху, діафрагми з боків.
3. **Скорочення льотка**: 6-8 мм (мишозахисна сітка).
4. **Перевірка кормів**: ≥2 кг меду на рамку.
5. **Установка зимівника**: для кочових пасік.

### Листопад

1. **Зимівля**: перенесення вуликів у зимівник (якщо є).
2. **Контроль**: прослуховування вуликів.
3. **Миші**: перевірка мишозахисних сіток.
4. **Планування**: аналіз сезону, підготовка до наступного.

## 35.6. Практичний підсумок

1. **Зима (грудень-лютий)**: контроль зимівлі (прослуховування 1 раз/2 тижні), очистка льотків від снігу, перевірка мишозахисних сіток, планування сезону, закупівля інвентарю, приготування канди/сиропу, ремонт інвентарю.
2. **Весна (березень-травень)**: перший обльот при +8-10°C → ревізія гнізда (сила, матка, корми, підмор) → весняне скорочення → утеплення → підгодівля (сироп 1:1 або канди) → лікування нозематозу (Фумагілін-B) → розширення гнізда (1 рамка/тиждень) → моніторинг вароатозу (1 раз/місяць) → відводи при загрозі роїння → підсилення слабких сімей → медоноси (верба, клен, плодові, акація).
3. **Літо (червень-серпень)**: медозбір (акація, липа, гречка, соняшник, золотушник) → відкачка меду (перша — акація, друга — липа, третя — гречка/соняшник) → контроль роїння (вирізання маточників, додавання магазинів) → моніторинг вароатозу (1 раз/місяць літо, 1 раз/2 тижні осінь) → лікування вароатозу після відкачки (обов'язково) → кочівля до пізніх медоносів → підготовка кормових запасів (20-25 кг/сім'я).
4. **Осінь (вересень-листопад)**: остання відкачка → підгодівля цукровим сиропом 2:1 → лікування вароатозу (осіннє, обов'язково до вересня) → скорочення гнізда (прибрати зайві рамки) → останній обльот при +10-12°C → утеплення (подушка 10 см, діафрагми) → скорочення льотка 6-8 мм → перевірка кормів (≥2 кг меду на рамку) → установка зимівника → контроль зимівлі.
5. **Медоноси Полтавщини**: березень — верба, ліщина, проліски; квітень — клен, плодові, акація (кінець квітня-початок травня), кульбаба; травень — акація (середина травня-початок червня), конюшина, ріпак; червень — акація, липа (кінець червня-початок липня), гречка (ранні сорти); липень — липа, гречка (середина липня-серпень), соняшник (початок); серпень — гречка, соняшник (середина серпня-вересень), золотушник (кінець серпня-жовтень); вересень — соняшник, золотушник, фацелія; жовтень — золотушник, плющ; листопад-лютий — без медозбору (зимівля).
