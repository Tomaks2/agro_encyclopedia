## 18.1. Що таке перга

Перга («бджолиний хліб») — пилок, утрамбований бджолами в стільникові комірки, залитий медом і закритий восковою кришечкою. Під восковою кришечкою відбувається молочнокисле бродіння → молочна кислота консервує пилок → біодоступність білка значно вища, ніж у свіжого пилку.

### Відмінності: пилок vs перга

| Параметр | Пилок (обніжжя) | Перга |
|---|---|---|
| **Біодоступність білка** | 60-70% | 90-95% (молочна кислота розщеплює оболонку пилку) |
| **Алергенність** | Вища (оболонка пилку) | Нижча (оболонка розщеплена) |
| **Зберігання** | Сушений: 1-2 роки; свіжий: тижні | 1-2 роки (в стільнику або очищений) |
| **Смак** | Гіркуватий, сухий | Кисло-солодкий, м'який |
| **Консервація** | Сушіння | Молочна кислота (природна) |
| **Ціна** | Дешевша | Дорожча (складніший збір) |

## 18.2. Біохімічний склад

| Компонент | Частка | Особливості |
|---|---|---|
| **Білки** | 20-40% | Всі незамінні амінокислоти; біодоступність 90-95% |
| **Цукри** | 25-35% | Глюкоза, фруктоза (з меду) |
| **Молочна кислота** | 1-3% | Консервант; розщеплює оболонку пилку |
| **Ліпіди** | 3-8% | Жирні кислоти, каротиноїди |
| **Мінерали** | 2-4% | Калій, магній, залізо, цинк, селен |
| **Вітаміни** | A, C, E, група B | Високі концентрації |
| **Ферменти** | Амілаза, протеаза | Бджолині ферменти |

### Чому перга краща за пилок

1. **Молочна кислота** розщеплює целюлозну оболонку пилку → білок засвоюється на 90-95% (пилок — 60-70%).
2. **Ферментація** знижує алергенність (оболонка — основний алерген).
3. **Природна консервація** — не потребує сушіння, не пліснявіє.
4. **Додаткові метаболіти** ферментації — пробіотичний ефект.

## 18.3. Збір перги

### Метод 1: Зрізання стільників з пергою (найпростіший)

1. **Відібрати рамки** з пергою (темні плями в стільнику — перга; бджоли зберігають в центрі гнізда).
2. **Зрізати** стільники з пергою ножом (не металевим, щоб не окислювати).
3. **Зберігати** в морозилці (-18°C) або сушити при 30-35°C.
4. **Продуктивність**: 2-5 кг/сім'я/сезон (залежить від сили та медозбору).

### Метод 2: Віджимання через сито

1. Вирізати стільники з пергою.
2. Віджати через сито (0,5-1 мм).
3. Перга проходить, воск залишається.
4. Сушити при 30-35°C (не вище — руйнування ферментів).

### Метод 3: Перфоратор (професійний)

1. Спеціальний пристрій з голками.
2. Проколюють стільник з пергою.
3. Перга випадає через отвори.
4. Швидко, чисто, без воску.

### Метод 4: З пилкових рамок (комбінований)

1. Пилкові рамки (бджоли збирають пилок у магазини).
2. Через 2-3 дні пилок переробляється в пергу.
3. Зняти рамки → зрізати стільники → віджати/перфорувати.

## 18.4. Зберігання перги

| Умова | Термін | Примітки |
|---|---|---|
| **В стільнику (закрита воском)** | 2-3 роки (морозилка -18°C) | Найкраще зберігання; природна консервація |
| **Очищена (без воску)** | 1-2 роки (морозилка -18°C) | Сушена при 30-35°C → герметична тара |
| **З медом (1:1)** | 1-2 роки (холодильник +4°C) | Консервація медом |
| **Кімнатна t** | 1-2 місяці | Ризик плісняви, жуків |

> ⚠️ **Перга не переносить вологість.** При вологості >60% — пліснява. Зберігати в герметичній тарі, темне місце, холод.

## 18.5. Застосування

### Дозування

1. **Дорослі**: 1 ч.л. (5-10 г) 2-3 рази/день.
2. **Діти (3-12 років)**: 0,5 ч.л. 1-2 рази/день.
3. **Прийом**: під язик (розсмоктування) або з медом (1:1).
4. **Курс**: 30 днів → перерва 30 днів → повтор.

### Показання (традиційне застосування)

- Анемія (залізо, білок).
- Відновлення після навантажень (білки, амінокислоти).
- Імуномодуляція.
- Відновлення після хвороб, операцій.
- Алергії (десенсибілізація — поступове звикання до пилку).
- Проблеми шлунково-кишкового тракту (пробіотичний ефект).

### Протипоказання

- Алергія на бджолині продукти (рідше, ніж на пилок).
- Гострі інфекції (перші дні).
- Вагітність (обережно).

## 18.7. Молекулярна біохімія перги

### Ферментація пилку → перга

1. **Пилок** утрамбовується в стільники
2. Заливається **медом** (консервація)
3. Закривається **воском** (анаеробні умови)
4. **Lactobacillus kunkeei** та ін. лактобактерії → молочнокисле бродіння
5. **Молочна кислота** (L-lactate, D-lactate) → pH < 4,0
6. **Біодоступність білка**: 60-70% (пилок) → 90-95% (перга)

### Ключові молекули

| Сполука | Функція |
|---|---|
| **Молочна кислота (L/D-lactate)** | Консервація, pH < 4,0; розщеплення пилкової оболонки (exine) |
| **Лактобактерії (L. kunkeei)** | Пробіотичний ефект; вироблення бактеріоцинів |
| **Флавоноїди (кверцетин, кемпферол)** | Антиоксидантний, протизапальний |
| **Поліфеноли** | Антиоксидантний ( scavenging free radicals) |
| **Амінокислоти (22)** | Всі незамінні; високі рівні проліну, лізину |
| **Вітаміни (група B, C, E, K)** | Високі концентрації; синтез B12 бактеріями |
| **Мікроелементи (Fe, Zn, Mg, Se)** | Гематопоез, імунітет |

### Біодоступність білка: механізм

- **Пилок**: оболонка (exine) — спороліпідин; стійка до травних ферментів → біодоступність 60-70%
- **Перга**: молочна кислота + ферменти лактобактерій → розщеплення exine → біодоступність 90-95%
- **Доказ**: клінічні дослідження показують вищу засвоюваність амінокислот з перги vs пилку

## 18.6. Практичний підсумок

1. **Перга** — пилок, утрамбований в стільники, залитий медом, закритий воском; молочнокисле бродіння → молочна кислота.
2. **Біодоступність білка**: 90-95% (перга) vs 60-70% (пилок) — молочна кислота розщеплює оболонку.
3. **Склад**: білки 20-40%, цукри 25-35%, молочна кислота 1-3%, ліпіди 3-8%, мінерали, вітаміни, ферменти.
4. **Збір**: зрізання стільників з пергою → морозилка; або віджимання через сито; або перфоратор (професійний).
5. **Продуктивність**: 2-5 кг/сім'я/сезон.
6. **Зберігання**: в стільнику — 2-3 роки (морозилка -18°C); очищена — 1-2 роки; з медом (1:1) — 1-2 роки (холодильник).
7. **Застосування**: 1 ч.л. (5-10 г) 2-3 рази/день; під язик або з медом; курс 30 днів → перерва 30 днів.
