## 15.1. Фізико-хімічний склад меду

### Цукри (75-80% сухої маси)

| Цукор | Частка | Властивість |
|---|---|---|
| Фруктоза | 38-40% | Найсолодший; повільно кристалізується |
| Глюкоза | 30-32% | Менш солодка; швидко кристалізується |
| Сахароза | 1-2% | Незначна (інвертаза перетворила) |
| Мальтоза | 3-5% | Проміжний продукт |

### Ферменти (біологічна цінність)

1. **Інвертаза (сахараза)**: перетворює сахарозу → глюкоза + фруктоза. Маркер зрілості.
2. **Діастаза (амілаза)**: розщеплює крохмаль. Маркер якості (одиниці Готе ≥7 за ДСТУ; свіжий мед 15-30).
3. **Глюкозооксидаза**: глюкоза → глюкозна кислота + H₂O₂ (перекис водню) → антибактеріальна дія + кислий pH (3,5-4,5).
4. **Каталаза, ліпаза, протеаза** — менші частки.

> 📌 **Головне**: мед — не просто цукор. Це живий продукт з ферментами, антиоксидантами, мінералами. Нагрівання >40°C руйнує ферменти → мед стає «мертвим цукром».

### Мінерали та вітаміни

Калій (720 мг/кг), кальцій, магній, залізо, мідь, цинк. Вітаміни: B1, B2, B6, C (невеликі кількості). Амінокислоти: пролін (200-1000 мг/кг — маркер зрілості).

### Антиоксиданти

Флавоноїди (піноцембрин, кверцетин), фенольні кислоти, інгібін (перекис водню). Темні сорти (гречка) — більше антиоксидантів, ніж світлі (акація).

## 15.2. Сор
ти Полтавщини

### Акацієвий мед

- **Травень**: акація біла (150-500 кг/га) — головний товарний мед Полтавщини.
- **Колір**: прозорий, світло-жовтий (майже безбарвний).
- **Кристалізація**: повільна (місяці; іноді не кристалізується рік) — багато фруктози.
- **Смак**: ніжний, солодкий, без гіркоти.
- **Застосування**: дієтичний (діабетики обережно, але менше глюкози → повільніший підйом цукру).

### Липовий мед

- **Червень — початок липня**: липа (до 1000 кг/га; пік 25 червня — 5 липня).
- **Колір**: світлий, іноді з зеленуватим відтінком.
- **Смак**: сильний, ароматний, з легкою гіркотою.
- **Кристалізація**: швидка (2-4 тижні), дрібнозерниста.
- **Застосування**: застуда, горло, потогінний.

### Гречаний мед

- **Липень — серпень**: гречка (60-100 кг/га).
- **Колір**: темно-коричневий, червонуватий.
- **Смак**: насичений, терпкий, з гіркотою.
- **Кристалізація**: швидка (2-4 тижні), крупнозерниста.
- **Застосування**: найбільше антиоксидантів (темний мед); анемія (залізо), відновлення.

### Соняшниковий мед

- **Серпень**: соняшник (пік; 40-50 кг/га).
- **Колір**: золотисто-жовтий, іноді зеленуватий.
- **Смак**: легкий, з легкою терпкістю.
- **Кристалізація**: дуже швидка (1-2 тижні), крупнозерниста.
- **Застосування**: загальний столовий мед.

### Поліфлорний (змішаний)

Бджоли збирають з кількох медоносів одночасно. Колір, смак, кристалізація — залежать від складу. Полтавщина: часто акація + конюшина (травень-червень), липа + гречка (липень).

## 15.3. Зберігання меду

### Оптимальні умови

| Параметр | Норма | Чому |
|---|---|---|
| Температура | 5-10°C (підвал) або 18-20°C (кімната) | Вище 40°C — руйнування ферментів |
| Світло | Темне | УФ руйнує інгібін та антиоксиданти |
| Вологість повітря | &lt;60% | Мед гігроскопічний — вбирає вологу → бродіння |
| Тара | Скляна, пластик харчовий, нержавійка | Не метал (окислення) |
| Герметичність | Щільна кришка | Запобігання вбиранню вологи та запахів |

### Термін зберігання

При правильних умовах — 2+ роки без втрати якості. Свіжий мед (до 3 міс) — рідкий, ферменти на максимумі. Кристалізований (3 міс+) — природний стан, не псування.

### Кристалізація

- **Швидка**: гречка (2-4 тижні), соняшник (1-2 тижні), ріпак (2-4 тижні).
- **Повільна**: акація (місяці), верес (місяці або не кристалізується), липа (4-8 тижнів).
- **Розтоплення**: водяна баня ≤40°C. Вище 40°C — незворотне руйнування ферментів, підвищення HMF.

## 15.4. Фальсифікація меду

<LightboxImage src="/photos/bdzhilnytstvo/P031_skhema-31-falsyfikatsiya-medu-yak-vyyavyty.png" alt="фальсифікація меду" />
*фальсифікація меду*


### Типи фальсифікації

1. **Розведення цукровим сиропом**: бджоли годуються цукром замість нектару.
2. **Розведення водою**: знижує концентрацію, підвищує вологість → бродіння.
3. **Додавання крохмалю**: загущування.
4. **Додавання борошна**: загущування.
5. **Підміна сорту**: продають дешевий (соняшник) як дорогий (акація).
6. **Нагрівання**: старий кристалізований мед розтоплюють → втрата ферментів.

### Як перевірити (домашні методи)

| Метод | Що перевіряє | Норма |
|---|---|---|
| **Йод** | Крохмаль | Капля йоду на мед: синій/фіолетовий — є крохмаль (фальсифікат) |
| **Оцет** | Крейда/борошно | Мед + оцет: піна — є крейда/борошно |
| **Вода** | Розчинення | Мед у воді: розчиняється повільно, без мути — натуральний |
| **Хліб** | Вологість | Хліб у меді на 10 хв: твердий — мед стиглий; м'який — вологий/розведений |
| **Папір** | Вологість | Крапля на папір: не розтікається — стиглий |
| **Нітрат срібла** | Цукровий сироп | Лабораторний метод: підвищена сахароза — годівля цукром |
| **Діастазне число** | Ферменти | Лабораторія: ≥7 од. Готе (ДСТУ); свіжий 15-30 |

## 15.6. Молекулярна біохімія меду

### Ферментний комплекс

| Фермент | ЕК | Функція | Продукт |
|---|---|---|---|
| Інвертаза (α-глюкозидаза) | EC 3.2.1.20 | Гідроліз сахарози → | Глюкоза + фруктоза |
| Глюкозооксидаза | EC 1.1.3.4 | Глюкоза + O₂ → | Глюконова кислота + H₂O₂ |
| Діастаза (α-амілаза) | EC 3.2.1.1 | Крохмаль → | Мальтоза |
| Каталіза | EC 1.11.1.6 | Розщеплення H₂O₂ | H₂O + O₂ |

Діастазне число (одиниці Готе, Schade): ДСТУ ≥7, CODEX ≥8, ЄС premium ≥14. Свіжий мед — 15-30.

### Шість антимікробних механізмів

1. **Osmolarity** — ~80 % цукрів, Aw 0.5-0.65 → плазмоліз бактерій
2. **Low pH** — 3.2-4.5 → інгібування росту
3. **H₂O₂ (enzymatic)** — глюкозооксидаза → окислювальний стрес
4. **Methylglyoxal (MGO)** — Manuka: DHA → MGO, non-peroxide activity
5. **Bee defensin-1** — антимікробний пептид (MRJP1-precursor)
6. **Флавоноїди** — кверцетин, кемпферол

### Maillard reaction та HMF

Глюкоза/фруктоза + амінокислоти → HMF + Amadori products. Оптимальна температура 120°C, але реакція йде й при 25-40°C при тривалому зберіганні. Пролін знижується при Maillard (реагує з цукрами).

### Кристалізація та F/G ratio

| Мед | F/G | Поведінка |
|---|---|---|
| Акацієвий | >2.0 | Рідкий роками |
| Середній | ~1.2:1 | Кристалізація за 2-6 міс. |
| Ріпаковий | &lt;1.0 | Швидка кристалізація |

Оптимальна температура кристалізації: 10-15°C. Фруктоза >1.2 → повільна кристалізація.

> ⚠️ **Домашні методи — орієнтовні.** Точна перевірка — лабораторія (діастаза, HMF, сахароза, ізотопний аналіз C3/C4). Якщо мед дешевший за ринкову ціну — підозра.

### Лабораторні показники натуральності

| Показник | Натуральний мед | Фальсифікат |
|---|---|---|
| Діастазне число | 15-30 (свіжий); ≥7 (ДСТУ) | &lt;5 (нагрітий/старий) |
| HMF | &lt;10 мг/кг (свіжий); ≤25 (ДСТУ) | >40 (нагрітий) |
| Сахароза | 1-3% | >6% (годівля цукром) |
| Пилок | Є (під мікроскопом) | Відсутній (профільтрований сироп) |
| Пролін | 200-1000 мг/кг | &lt;100 (сироп) |

## 15.5. Практичний підсумок

1. **Склад**: фруктоза 38-40%, глюкоза 30-32%, вода ≤20%; ферменти (інвертаза, діастаза, глюкозооксидаза) — біологічна цінність.
2. **Сорти Полтавщини**: акація (травень, світлий, повільно кристалізується), липа (червень, ароматний, потогінний), гречка (липень-серпень, темний, антиоксиданти), соняшник (серпень, золотистий, швидка кристалізація).
3. **Зберігання**: 5-10°C або 18-20°C, темне, вологість &lt;60%, скляна/пластик/нержавійка, герметично. 2+ роки.
4. **Кристалізація** — природний процес, не псування. Розтоплювати ≤40°C.
5. **Фальсифікація**: розведення сиропом/водою, додавання крохмалю/борошна, підміна сорту, нагрівання. Домашні тести: йод (крохмаль), оцет (крейда), хліб (вологість), папір (вологість). Точно — лабораторія (діастаза, HMF, сахароза).
6. **Натуральний мед**: діастаза ≥7, HMF ≤25, сахароза ≤6%, пилок присутній, пролін 200-1000 мг/кг.
