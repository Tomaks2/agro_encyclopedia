## 10.1. Загальна медопродуктивність Полтавщини

Сумарна медопродуктивність Полтавської області: **80–150 кг/га за сезон** (природні + культурні медоноси). При правильному управлінні одна сім'я на Полтавщині дає **40–80 кг товарного меду** за сезон (без підгодівлі). Пік медозбору — травень (акація) та липень-серпень (липа, гречка, соняшник).

## 10.2. Календар медоносів по місяцях
<LightboxImage src="/photos/bdzhilnytstvo/P052_skhema-52-medonosy-poltavshchyny-po-misyatsyakh.png" alt="СХЕМА 52: Медоноси Полтавщини по місяцях" />

### **Квітень** (підтримуючий медозбір, 5–15 кг/сім'я)

| Медонос | Медопродуктивність | Особливості |
|---|---|---|
| Верба (лазозілля, козяча) | 100–150 кг/га | Перший пилок + нектар; пробудження сімей |
| Кульбаба лікарська | 40–50 кг/га | Пилок, нектар; масовий у степових зонах |
| Ріпак озимий | 80–100 кг/га | Ранній нектар; але мед швидко кристалізується |
| Яблуня (сади) | 15–20 кг/га | Полтавщина — садівничий регіон |
| Груша, вишня, слива | 10–15 кг/га | Садові культури |
| Кульбаба + гірчак | 20–30 кг/га | Додатковий пилок |

> 📌 **Квітень — підтримуючий медозбір.** Сім'ї нарощують силу, не відбирають мед. Мета: до травня сім'я має 8–10 рамок бджіл.

### **Травень** (головний товарний медозбір — акація)

| Медонос | Медопродуктивність | Особливості |
|---|---|---|
| **Акація біла (робінія)** | **150–500 кг/га** | **Головний товарний мед Полтавщини**; рідко кристалізується; 2–3 тижні цвітіння (10–30 травня) |
| Конюшина біла | 60–100 кг/га | Стабільний, але залежить від вологи |
| Гірчак | 20–40 кг/га | Пилок, додаток |
| Шавлія лучна | 100–200 кг/га | Степові ділянки |
| Сад (яблуня, груша) | 15–25 кг/га | Друга хвиля |

> 📌 **Акація — стратегічний медозбір Полтавщини.** 2–3 тижні інтенсивного збору (10–30 травня). Сім'я повинна бути максимально сильною до 1 травня (10+ рамок бджіл). Відбір акацієвого меду — червень.

### **Червень** (липа — пік)

| Медонос | Медопродуктивність | Особливості |
|---|---|---|
| **Липа дрібнолиста** | **500–1000 кг/га** | **Пік 25 червня — 5 липня**; головний літній медозбір |
| Гречиха посівна (1-й посів) | 60–100 кг/га | Ранній посів; темний мед |
| Фацелія | 150–300 кг/га | Якщо висіяна; ідеальний медонос |
| Соняшник (ранні сорти) | 20–40 кг/га | Початок |

> 📌 **Липа — другий стратегічний медозбір.** Цвіте 10–14 днів, пік — 25 червня — 5 липня. Якщо спекотно + сухо → цвітіння скорочується до 5–7 днів. Готовність сім'ї: 12+ рамок бджіл.

### **Липень** (гречка, соняшник)

| Медонос | Медопродуктивність | Особливості |
|---|---|---|
| Гречиха посівна | 60–100 кг/га | Темний, ароматний мед; 15–30 липня |
| Соняшник (основний) | 40–50 кг/га | Масовий у Полтавській області |
| Липа (затяжна) | 100–300 кг/га | Якщо цвітіння затягнулося |
| Материнка, чебрець | 50–100 кг/га | Степові ділянки |

### **Серпень** (соняшник — пік + золотушник)

| Медонос | Медопродуктивність | Особливості |
|---|---|---|
| **Соняшник** | **40–50 кг/га** | **Пік: 1–20 серпня**; Полтавщина — соняшникова зона |
| Гречиха (2-й посів) | 30–60 кг/га | Якщо висіяна |
| **Золотушник канадський** | **100–200 кг/га** | **Інвазивний, але потужний осінній медонос** |
| Фацелія (2-й посів) | 100–150 кг/га | Якщо висіяна в липні |

### **Вересень** (осінній підтримуючий)

| Медонос | Медопродуктивність | Особливості |
|---|---|---|
| Золотушник канадський | 100–200 кг/га | Основний осінній медонос |
| Верес звичайний | 50–100 кг/га | Лісові ділянки, піщані ґрунти |
| Осіння фацелія | 50–100 кг/га | 2-й посів |
| Айстра, жовтозілля | 20–40 кг/га | Додатковий |

> 📌 **Вересень — останній медозбір.** Мета: набрати 20–25 кг корму на зиму. Після 15 вересня медозбір зазвичай закінчується.

### **Жовтень–Березень**

Медоносів немає. Сім'ї живуть на зимових запасах (20–25 кг меду або канди/сиропу).

## 10.3. Стратегія медозбору для Полтавщини
<LightboxImage src="/photos/bdzhilnytstvo/P053_skhema-53-holovni-tovarni-medonosy-poltavshchyny.png" alt="СХЕМА 53: Головні товарні медоноси" />

### Два головні товарні медозбори:
1. **Акація (травень)** — 30–50 кг/сім'я
2. **Липа + гречка + соняшник (червень–серпень)** — 30–50 кг/сім'я

**Сумарно: 60–100 кг товарного меду/сім'я/сезон** при правильному управлінні.

### Ключові правила:
1. **До 1 травня** сім'я повинна мати 8–10 рамок бджіл (інакше акацію «пропустить»).
2. **До 20 червня** сім'я повинна мати 12+ рамок (для липи).
3. **Після акації** — не відбирати весь мед: залишити 10–12 кг на розплід.
4. **Після липи** — відбір товарного меду, початок підготовки до зими.
5. **Вересень** — формування зимового гнізда (24–28 л), корм 20–25 кг.

## 10.4. Медопродуктивність по районах Полтавщини

| Район | Особливості медоносів | Очікуваний медозбір/сім'я |
|---|---|---|
| Полтавський, Диканський | Сади + акація + липа | 60–90 кг |
| Кременчуцький, Глобинський | Соняшник + гречка + ріпак | 50–80 кг |
| Лубенський, Хорольський | Акація + липа + гречка | 60–100 кг |
| Миргородський, Гадяцький | Липа + гречка + сади | 70–100 кг |
| Полтавщина північна (Гадяч, Лохвиця) | Липа + гречка + фацелія | 60–90 кг |
| Полтавщина південна (Нові Санжари, Кобеляки) | Соняшник + ріпак + гречка | 50–70 кг |

## 10.5. Практичний підсумок

1. **Головні медоноси Полтавщини**: акація (травень), липа (червень–липень), гречка + соняшник (липень–серпень), золотушник (вересень).
<LightboxImage src="/photos/bdzhilnytstvo/P021_skhema-21-holovni-medonosy-poltavshchyny-detalizatsiya.png" alt="головні медоноси" />

2. **Підтримуючі**: верба + кульбаба + ріпак (квітень), конюшина (травень), фацелія (червень, вересень).
3. **Стратегія**: до акації — 8–10 рамок бджіл; до липи — 12+; після липи — відбір товарного меду; вересень — зимове гніздо 24–28 л, корм 20–25 кг.
4. **Очікуваний товарний мед**: 60–100 кг/сім'я/сезон при правильному управлінні.
