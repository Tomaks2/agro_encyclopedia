## 14.1. Коли ставити магазини

### Магазини (напіврамки 435×145 мм)

Магазин — надставка над розплідним корпусом для збору меду. Ставити при початку медозбору (нектар надходить).

### Правила

1. **Коли ставити**: при появі нектару (акація — травень, липа — червень, соняшник — серпень).
2. **Скільки магазинів**: 1 магазин на сильну сім'ю; 2 магазини — на дуже сильну (12+ рамок).
3. **Не ставити магазини без медозбору**: бджоли не будуть будувати порожні стільники.
4. **Зняти магазини після закінчення медозбору**: щоб бджоли не витрачали енергію на обігрів порожнього простору.

## 14.2. Визначення стиглості меду

### Метод 1: Рефрактометр (найточніший)

Вологість &lt;20% — мед стиглий, можна відкачувати. >21% — недостиглий, бродитиме.

### Метод 2: Візуальний

Запечатані кришечки воском на 2/3+ рамки — мед стиглий. Незапечатані комірки — недостиглий.

### Метод 3: «Нитка»

Занурити ложку в мед, підняти: стиглий мед тече повільною безперервною ниткою, лягає «гіркою». Недостиглий — рідкий, капає.

### Метод 4: Папір

Крапля меду на папір: стиглий не розтікається, недостиглий — розтікається (волога вбирається в папір).

> 📌 **Золотий стандарт: рефрактометр.** Вологість &lt;20% — медозбір можна відкачувати. ДСТУ 4497:2005: вологість ≤21%.

## 14.3. Відкачка меду

### Крок 1: Зняти магазини/рамки

Вечором або рано вранці (бджоли спокійніші). Використати димар.

### Крок 2: Зняти бджіл з рамок

Щітка (зметати) або струшувати (різко, над вуликом — бджоли падають назад).

### Крок 3: Зрізати кришечки (запечат)

Ніж для зрізу (електро або звичайний з зубцями). Зрізати тонкий шар воску з обох боків рамки.

### Крок 4: Відкачка в медогонці

1. Поставити рамки в медогонку (радіальну або хордіальну).
2. Крутити (ручну — 5–10 хв, електро — 2–3 хв).
3. Мед стікає по стінках → зливний отвір → фільтр → ємність.
4. Перевернути рамки (хордіальна) або продовжити (радіальна).

### Крок 5: Фільтрація

Мед проходить через сітку 0,3–0,5 мм → видаляються частинки воску, пилку, бджіл.

### Крок 6: Відстій

Мед стоїть 2–3 дні в ємності → бульбашки повітря піднімаються → зняти піну.

## 14.4. ДСТУ 4497:2005 (стандарт меду в Україні)

### Фізико-хімічні показники

| Показник | Норма |
|---|---|
| Вологість | ≤21% (краще &lt;20%) |
| Діастазне число | ≥7 од. Готе (краще ≥10) |
| HMF (оксиметилфурфурол) | ≤25 мг/кг |
| Редуковані цукри | ≥65% |
| Сахароза | ≤6% (краще &lt;3%) |
| Кислотність | ≤4 см³ 1н NaOH |
| Електропровідність | Залежить від сорту |

### Органолептичні показники

| Показник | Норма |
|---|---|
| Колір | Від безбарвного до темно-коричневого (залежить від сорту) |
| Запах | Від ніжного до сильного (залежить від медоносу) |
| Смак | Солодкий, без сторонніх присмаків |
| Консистенція | Рідка (свіжий) або кристалізована (витриманий) |
| Пінистість | Не допускається (ознака бродіння) |

> ⚠️ **Заборонено**: мед з антибіотиками, мед з ГМО-пилку, мед з годівлі цукром під час медозбору.

## 14.5. Зберігання меду

### Умови

| Параметр | Оптимально |
|---|---|
| Температура | 5–10°C (підвал) або 18–20°C (кімната) |
| Вологість повітря | &lt;60% |
| Світло | Темне (УФ руйнує ферменти) |
| Тара | Скляна, пластик харчовий, нержавійка (не метал!) |
| Термін | 2+ роки (правильне зберігання) |

### Кристалізація

Мед кристалізується — це природний процес, не ознака фальсифікації. Швидкість: ріпак/соняшник — 2–4 тижні; акація/верес — місяці (або не кристалізується).

### Розтоплення кристалізованого меду

Температура ≤40°C (водяна баня). Вище 40°C — руйнуються ферменти (діастаза), підвищується HMF.

## 14.7. Типові помилки медозбору

| Помилка | Наслідок | Правильно |
|---|---|---|
| Відкачати недостиглий мед (>21%) | Бродіння, кислий мед, втрата товару | Рефрактометр: тільки &lt;20% |
| Зняти магазини в спеку (полудень) | Бджоли агресивні, ризик нападів | Вечір або рано вранці |
| Не зняти бджіл з рамок | Бджоли в медогонці, мед забруднений | Щітка або струшування |
| Зрізати товстий шар воску | Втрати меду в зрізі | Тонкий шар (1–2 мм) |
| Відкачувати з металевими деталями | Окислення меду | Нержавійка або пластик |
| Не фільтрувати мед | Частинки воску, пилку, ніжки бджіл | Сітка 0,3–0,5 мм |
| Розлити гарячий мед (>45°C) | Руйнування ферментів, HMF росте | Тільки кімнатна температура |
| Зберігати на сонці | УФ руйнує діастазу, потемніння | Темне місце |
| Зберігати в оцинкованому відрі | Отруєння цинком | Скляна/пластик/нержавійка |

## 14.8. Відбір останнього меду перед зимівлею

**Правило**: залишити бджолам достатньо корму на зиму!

**Норми корму на зиму (Полтавщина)**:
- Сильна сім'я (8+ рамок): 25–30 кг меду
- Середня (6–7 рамок): 20–25 кг
- Слабка (4–5 рамок): 15–18 кг (або підсилити/об'єднати)

**Як визначити скільки відібрати**:
1. Зважити вулик (без магазину): сильна сім'я ≈ 50–60 кг
2. Порахувати рамки меду в розплідному корпусі
3. Відібрати тільки магазинний мед (не чіпати розплідний!)
4. Якщо розплідний корпус має &lt;15 кг — не відбирати зовсім

**Підгодівля після відбору (серпень)**:
- Сироп 2:1 (цукор:вода) — 10–15 л на сім'ю
- Давати по 1–2 л/вечір (дрібними дозами)
- Термін: до 10–15 вересня (бджоли повинні встигнути переробити)

> ⚠️ **Не годувати пізно (жовтень)** — бджоли не встигнуть переробити сироп, він закристалізується в стільниках і буде непридатний для зимівлі.

## 14.9. Розлив та пакування меду

**Тара**:
- Скляні банки (0,5 л, 1 л): оптимально для продажу
- Пластик харчовий (PET): дешевший, легший
- Відра харчові (10 л, 20 л): для оптужих покупців

**Етикетка (обов'язково для продажу)**:
- Назва продукту: «Мед натуральний квітковий»
- Місце збору: Полтавська обл., Україна
- Дата відкачки
- Вага нетто
- Контакт пасічника (телефон)
- Зберігати при температурі не вище 20°C

**Пакування**:
- Заповнювати банку доверху (без повітря — менше окислення)
- Кришка щільна (герметична)
- Не пакувати гарячий мед (конденсат → бродіння)

## 14.10. Економіка медозбору (Полтавщина)

**Середній медозбір на сім'ю за сезон**:

| Медонос | Термін | Медозбір/сім'я | Ціна/кг (2025) |
|---|---|---|---|
| Акація | Травень | 15–30 кг | 200–300 грн |
| Липа | Червень–липень | 10–20 кг | 150–250 грн |
| Соняшник | Серпень | 15–35 кг | 100–180 грн |
| Гречка | Серпень–вересень | 10–25 кг | 150–200 грн |
| Різнотрав'я | Червень–липень | 10–20 кг | 120–200 грн |
| **Разом за сезон** | | **40–80 кг** | |

**Дохід з 5 вуликів** (середній сценарій 50 кг/сім'я × 5 = 250 кг × 150 грн = 37 500 грн/сезон).

**Витрати на сезон** (5 вуликів): ~10 000–15 000 грн (ліки, корм, вощина, обладнання, амор.).

**Чистий прибуток**: 22 000–27 000 грн/сезон (без урахування праці).

## 14.6. Практичний підсумок

1. **Магазини**: ставити при початку медозбору (1 магазин на сильну сім'ю, 2 — на дуже сильну). Зняти після закінчення.
2. **Стиглість**: рефрактометр (вологість &lt;20%) або візуально (2/3+ рамки запечатані).
3. **Відкачка**: зрізати кришечки → медогонка (радіальна — не перевертати, хордіальна — перевертати) → фільтр 0,3–0,5 мм → відстій 2–3 дні.
4. **ДСТУ 4497:2005**: вологість ≤21%, діастаза ≥7, HMF ≤25 мг/кг, сахароза ≤6%.
5. **Зберігання**: 5–10°C або 18–20°C, темне місце, вологість &lt;60%, скляна/пластик/нержавійка (не метал!).
6. **Кристалізація** — природний процес. Розтоплювати ≤40°C (вище — руйнує ферменти).
