<Callout type="important" title="Життєво важливий медичний протокол">
Отрута бджоли (*Апітоксин*) містить потужні біологічно активні пептиди. Для 98% людей укус викликає лише локальний набряк та біль, проте **для 1–2% осіб з алергією 1 типу укус може викликати анафілактичний шок**, що становить загрозу для життя без негайного введення **Адреналіну (Епінефрину)**.
</Callout>

## 10.1. Хімічний склад та токсикологія Апітоксину

| Активний компонент | Вміст у сухій речовині | Біологічна та фармакологічна дія |
| :--- | :--- | :--- |
| **Мелітин (Melittin)** | **40 – 50%** | Основний токсичний пептид, руйнує мембрани клітин, розширює судини, викликає біль |
| **Фосфоліпаза A_2** | **10 – 12%** | Сильний ферментативний алерген, розщеплює фосфоліпіди клітинних мембран |
| **Апамін (Apamin)** | **2 – 3%** | Нейротоксин, блокує кальцій-залежні калієві канали |
| **Пептид MCD** | **2%** | Руйнує тучні клітини, вивільняючи гістамін |
| **Гіалуронідаза** | **1 – 3%** | Фермент «проникнення», розщеплює сполучну тканину для швидкого розповсюдження отрути |

## 10.2. Перша допомога при поодинокому укусі бджоли

```
                  Покроковий протокол видалення жала та обробки
                 
      [ 1. Негайно зскребти жало нігтем або стамескою (НЕ СТИСКУВАТИ ПІНЦЕТОМ!) ]
                                       │
                                       ▼
      [ 2. Промити місце укусу водою з милом або антисептиком ]
                                       │
                                       ▼
      [ 3. Прикласти ЛІД або холодний компрес на 10–15 хвилин ]
                                       │
                                       ▼
      [ 4. Прийняти пероральний антигістамінний препарат (Цетиризин / Лоратадин) ]
```

## 10.3. Симптоми Анафілаксії та протокол ЕпіПен (Епінефрин)

<InfoBlock type="gold" icon="🚑" title="Алгоритм дій при анафілактичному шоці">
При появі кропивниці по всьому тілу, набряку губ/язика, утрудненого дихання чи запаморочення:
1. **Негайно ввести Адреналін (ЕпіПен / Автоінжектор 0.3 мг)** у зовнішню поверхню стегна в/м.
2. Викликати швидку медичну допомогу (103).
3. Покласти потерпілого на спину, піднявши ноги на 30 см (при блюванні — на бік).
</InfoBlock>
