<Callout type="warning" title="Критична операція: Осліплення нижніх вузлів">
Перші 4–5 пазух листків від землі (зони 0–50 см) називаються зоною «осліплення». У цих пазухах **ПОВНІСТЮ ВИДАЛЯЮТЬ УСІ ЖІНОЧІ ЗАВ'ЯЗІ ТА БОКОВІ ПАСИНКИ**. Якщо цього не зробити, нижні перші плоди виснажать слабку кореневу систему молодої рослини, що призведе до скидання всіх наступних зав'язей на висоті 1,0–2,0 м!
</Callout>

## 4.1. Схема формування огірка за методом «Парасолька» (Umbrella System)

<LightboxImage src="/photos/ohirok/charts/54_skhema_formuvannia_parasolka.png" alt="Схема формування «парасолька»" />


```
                    Схема шпалерного формування «Парасолька»
  
                      ===============================  ◄── Верхній дріт (2.2 м)
                      │    Перекинута верхівка      │      (Прищипування після 2 листків)
                      └──────────────┬──────────────┘
                                     │
                             ( Зав'язі на пагонах ) ──► Прищипування бокових на 2 листки
                                     │
                             ( Зав'язі на пагонах ) ──► Прищипування бокових на 1 листок
                                     │
                      ┌──────────────┴──────────────┐
                      │    Зона Осліплення (0-50см) │  ◄── ✂️ (Усі зав'язі та пасинки
                      └──────────────┬──────────────┘       видалено!)
                                    ─┴─ [Ґрунт]
```

1. **Зона 0 – 50 см (Нижні 4–5 вузлів):** Повне осліплення (видалення всіх квіток та пасинків).
2. **Зона 50 – 150 см:** Головне стебло прив'язують до шпагату. Бокові пасинки прищипують над **1-м листком** (залишаючи 1 плід).
3. **Зона 150 см – Верхній дріт (220 см):** Бокові пасинки прищипують над **2-м листком** (залишаючи 2 плоди).
4. **Верхній дріт (Парасолька):** Головне стебло перекидають через верхній дріт шпалери, прищипують верхівку на висоті 50 см донизу.

### 📌 СХЕМА 252: ЧОТИРИ ЗОНИ ФОРМУВАННЯ «ПАРАСОЛЬКА» (ВЕРХНІЙ ДРІТ 2,2 м)

| Зона | Висота | Операція |
| :--- | :--- | :--- |
| **1. Осліплення** | 0–50 см (4–5 вузлів) | ✂️ Видаляють **усі** зав'язі та пасинки — інакше скидання зав'язей на 1,0–2,0 м |
| **2. Нижня продуктивна** | 50–150 см | Пасинки прищипують над **1-м листком** (1 плід на пасинку) |
| **3. Верхня продуктивна** | 150–220 см (верхній дріт) | Пасинки прищипують над **2-м листком** (2 плоди на пасинку) |
| **4. Парасолька** | Після верхнього дроту | Головне стебло **перекидають через дріт**, верхівку прищипують на 50 см вниз |

### 📌 СХЕМА 253: ЕКОНОМІКА ЗАВ'ЯЗЕЙ: ЧОМУ ОСПІЛЕННЯ = ЗБЕРЕЖЕННЯ УРОЖАЮ

| Сценарій | Результат |
| :--- | :--- |
| **Без осліплення** | Перші плоди виснажують слабку кореневу систему → **скидання ВСІХ зав'язей** на висоті 1,0–2,0 м = втрата основного врожаю |
| **З осліпленням** | Корінь нарощує масу до фази BBCH 61–69 → рівномірне навантаження по всій довжині стебла |
| **Ритм обслуговування** | Прищипування + осліплення виконують **щотижня**, у напрямку знизу вгору, у суху погоду |

> 📌 **Головний підсумок розділу:** Метод «Парасолька» — чіткий зонний конвеєр: повне осліплення нижніх 4–5 вузлів (0–50 см) зберігає молодий корінь від виснаження і запобігає скиданню зав'язей на висоті 1,0–2,0 м; далі пасинки ведуть над 1-м листком у зоні 50–150 см (1 плід) і над 2-м листком вище 150 см (2 плоди); верхівку перекидають через верхній дріт (2,2 м) і прищипують на 50 см вниз. Усі операції виконують щотижня, знизу вгору, у суху погоду.
