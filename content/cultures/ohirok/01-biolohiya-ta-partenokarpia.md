<Callout type="important" title="Фундаментальне явище сучасної агрономії: Партенокарпія">
Партенокарпічні гібриди огірка (*Cucumis sativus* L., **2n = 14 хромосоми**) мають здатність зав'язувати повноцінні безнасінні плоди **БЕЗ ЗАПЛІДНЕННЯ І БЕЗ БДЖІЛ**. Усі квітки у партенокарпічних гібридів є жіночого типу (у пазусі кожного листка закладається від 1 до 5–7 жіночих зав'язей). Якщо на партенокарпічний огірок потрапить пилок від бджолозапильного сорту, плід деформується і набуває «грушоподібної» форми!
</Callout>

## 1.1. Морфологія огіркової рослини

<LightboxImage src="/photos/ohirok/charts/51_partenokarpiia_vs_bdzholozapylennia.png" alt="Партенокарпія vs бджолозапилення" />


1. **Лианоподібне стебло:** Однорічне, шорстко-опушене стебло з вусиками, яке у закритому ґрунті досягає довжини **3–6 метрів**.
2. **Коренева система:** Поверхнева, надзвичайно ніжна, залягає у шарі 0–20 см. Корені вимагають високої пухкості ґрунту (вміст органіки > 5%) та категорично не переносять найменшого пошкодження при розпушуванні.

## 1.2. Шкала фенологічних фаз BBCH для огірка

| Код BBCH | Фаза розвитку | Агротехнічний регламент |
| :--- | :--- | :--- |
| **BBCH 00–09** | Висів та поява сходів | Вимога t ґрунту **> +22...+25 °C** (сходи через 3–4 дні). |
| **BBCH 11–19** | Розгортання 1–5 справжніх листків | Досвічування розсади, висадка в ґрунт у віці 20–25 днів. |
| **BBCH 51–59** | Закладання жіночих зав'язей у пазухах | Осліплення нижніх 4–5 вузлів (0–50 см). |
| **BBCH 61–69** | Масове розпускання жіночих квіток | Шпалерна підв'язка, щоденна крапельна фертигація. |
| **BBCH 71–75** | Інтенсивний ріст зеленців | **ЩОДЕННИЙ ЗБІР УРОЖАЮ!** Захист від пероноспорозу. |

### 📌 СХЕМА 246: ПАРТЕНОКАРПІЯ VS БДЖОЛОЗАПИЛЬНІСТЬ: МАТРИЦЯ СУМІСНИХ ГІНЕЦЕЇВ

| Тип гінецю | Запилення | Результат |
| :--- | :--- | :--- |
| **Партенокарпічний** (женочі квітки) | **Без запилення** — зав'язь → безнасінний плід | ✅ Стандарт теплиць, 1–5–7 зав'язей у пазусі |
| **Партенокарпічний + чужий пилок** (бджолозапильний поруч) | Пилок потрапляє на квітку | ⚠️ Плід **деформується** → «грушоподібна» форма |
| **Бджолозапильний** | Обов'язкове запилення (бджоли/джмелі) | Плоди з насінням, товарна форма |

### 📌 СХЕМА 247: АНАТОМІЧНИЙ ПАСПОРТ ОГІРКА ТА BBCH

| Параметр | Значення |
| :--- | :--- |
| **Геном** | *Cucumis sativus* L., диплоїд **2n = 14** |
| **Стебло** | Лианоподібне, шорстко-опушене, з вусиками; у закритому ґрунті **3–6 м** |
| **Корінь** | Поверхневий, нічний, **0–20 см**; потребує органіки > 5%, не переносить пошкоджень |
| **BBCH 00–09 (сходи)** | t ґрунту **> +22...+25 °C**, сходи за 3–4 дні |
| **BBCH 51–59** | Закладання жіночих зав'язей → **осліплення нижніх 4–5 вузлів (0–50 см)** |
| **BBCH 71–75 (налив)** | Щоденний збір зеленців + захист від пероноспорозу |

> 📌 **Головний підсумок розділу:** Огірок (*Cucumis sativus*, 2n = 14) — лианоподібний однорічник із надзвичайно ніжним поверхневим коренем (0–20 см), який вимагає органіки > 5% і категорично не переносить пошкоджень. Ключове явище сучасної селекції — партенокарпія: жіночі гібриди зав'язують безнасінні плоди без запилення (1–5–7 зав'язей у пазусі кожного листка), але потрапляння чужого пилку з бджолозапильних сортів деформує плід у «грушоподібну» форму. За BBCH: сходи при t ґрунту > +22...+25 °C за 3–4 дні, осліплення нижніх 4–5 вузлів (0–50 см) на фазі закладання зав'язей, і щоденний збір на фазі наливання.
