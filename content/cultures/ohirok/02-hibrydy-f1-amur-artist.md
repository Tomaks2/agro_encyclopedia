<Callout type="tip" title="Типи шипуватості плодів огірка">
- **Дрібношипні (німецький тип):** Плід вкритий численними дрібними горбочками з дрібними шипами. Ідеальні для засолювання та маринування (ропав заходить через дрібні пори рівномірно).
- **Крупношипні (голландський тип):** Плід має рідкі великі горбки із чорними або білими шипами (Амур F1, Артист F1). Всесвітній стандарт для свіжого ринку.
- **Гладкі салатні (азіатський / галерейний тип):** Довгі плоди (20–30 см) з гладкою шкіркою без шипів.
</Callout>

## 2.1. Детальний аналіз провідних партенокарпічних гібридів F1

<LightboxImage src="/photos/ohirok/charts/52_try_typy_shypuvatosti_plodiv.png" alt="Три типи шипуватості плодів огірка" />


<InfoBlock type="gold" icon="👑" title="1. Амур F1 (Amour F1) — Bejo (Нідерланди)">
- **Особливість:** Ультраранній букетний партенокарпік (40–45 днів).
- **Плід:** Крупношипний корнішон довжиною **8–10 см**, темно-зелений, щільний, без гіркоти.
- **Навантаження:** Формує по **2–4 плоди у кожному вузлі**!

</InfoBlock>

<InfoBlock type="gold" icon="🥇" title="2. Артист F1 (Artist F1) — Bejo">
- **Особливість:** Потужна коренева система, надзвичайна регенерація після стресу.
- **Плід:** Однорідний крупношипний корнішон (співвідношення довжини до діаметру **3,1 : 1**).
- **Стійкість:** Імунний до кладоспоріозу та борошнистої роси.
</InfoBlock>

<InfoBlock type="gold" icon="🥈" title="3. Бйорн F1 (Bjorn F1) / Кібрія F1 (Rijk Zwaan)">
- **Бйорн F1:** Дуже ранній генеративний гібрид для першого та другого обігу теплиць. Плоди не переростають у товщину!
- **Кібрія F1:** Ультраранній надпродуктивний гібрид із високою віддачею раннього врожаю.
</InfoBlock>

## 2.2. Бджолозапильні гібриди відкритого ґрунту

- **Роднічок F1:** Легендарний бджолозапильний гібрид із винятковими засолювальними якостями (хрускіт без порожнеч). Вимагає наявності бджіл та гібридів-запилювачів.

### 📌 СХЕМА 248: ТРИ ТИПИ ШИПУВАТОСТІ = ТРИ КОМЕРЦІЙНІ НІШІ

| Тип | Зовнішність плода | Призначення |
| :--- | :--- | :--- |
| **Дрібношипні (німецький)** | Численні дрібні горбочки з дрібними шипами | **Засолювання/маринування** — розсіл заходить рівномірно через дрібні пори |
| **Крупношипні (голландський)** | Рідкі великі горбки з чорними/білими шипами | **Свіжий ринок** — всесвітній стандарт |
| **Гладкі салатні (азіатський)** | Гладка шкірка без шипів, плоди **20–30 см** | Свіже споживання, салати |

### 📌 СХЕМА 249: МАТРИЦЯ ВЕДУЧИХ ГІБРИДІВ F1

| Гібрид F1 | Селекція | Ключова особливість | Плод |
| :--- | :--- | :--- | :--- |
| **Амур F1** | Bejo (Нідерланди) | Ультраранній букетний (40–45 днів) | Крупношипний корнішон **8–10 см**, **2–4 плоди у вузлі** |
| **Артист F1** | Bejo | Потужний корінь, регенерація після стресу | Однорідний, співвідношення **довжина:діаметр = 3,1:1** |
| **Бйорн F1** | — | Дуже ранній генеративний, 1-й і 2-й обіг | Не переростає у товщину |
| **Кібрія F1** | Rijk Zwaan | Ультраранній надпродуктивний | Висока віддача раннього врожаю |
| **Роднічок F1** | Бджолозапильний (відкритий ґрунт) | Засолювальна класика | Хрускіт без порожнеч, потрібні бджоли + запилювачі |

> 📌 **Головний підсумок розділу:** Коммерційна логіка огірка будується від шипуватості: дрібношипні (німецький тип) з рівномірним проникненням розсолу — засолювальна ніша, крупношипні (голландський тип) — всесвітній стандарт свіжого ринку, гладкі азійські 20–30 см — салати. Матриця партенокарпіків F1: Амур F1 тримає букетність 2–4 плоди у вузлі при 8–10 см, Артист F1 — генетичну однорідність 3,1:1 із стійкістю до кладоспоріозу та борошнистої роси, Кібрія F1 — рекорд ранньої віддачі. Бджолозапильний Роднічок F1 залишається засолювальною легендою, але вимагає запилювачів.
