<Callout type="important" title="Небезпека переохолодження плодів томата (Chilling Injury)">
Томат є класичним **клімактеричним плодом**. Проте його категорично **ЗАБОРОНЕНО зберігати при температурі нижче +10...+12 °C**! При температурі нижче +10 °C у плодах руйнується судинна система, незворотно деградують леткі ароматичні сполуки (плоди втрачають томатний смак і стають «водянистими»), а при поверненні в тепло вони миттєво поражаються альтернаріозом.
</Callout>

## 8.1. Шкала стиглості плодів томата

<LightboxImage src="/photos/tomat/charts/49_dozariuvannia_etylenom_u_kameri.png" alt="Дозарювання етиленом у камері" />


1. **Зелена стиглість (Mature Green):** Плід досяг сортового розміру, насіннєві камери заповнені гелем. Придатний для далекого експорту.
2. **Бланжева / Зміна кольору (Breaker / Turning):** На носик плоду з'являється перша рожево-жовта пляма (до 10–30% поверхні). **Оптимальна стадія для масового комерційного збору!**
3. **Рожева стиглість (Pink):** 30–60% рожевого забарвлення.
4. **Повна червона стиглість (Red / Ripe):** 100% забарвлення. Призначений для швидкого споживання та переробки.

---

## 8.2. Технологія штучного дозарювання газом Етиленом

<LightboxImage src="/photos/tomat/charts/ripeness_scale_tomat.png" alt="Шкала стиглості томату" />


Для одночасного дозарювання збираних бланжевих томатів у герметичних камерах застосовують дозарювання етиленом:
- **Концентрація Етилену (C₂H₄):** **100 – 150 ppm** (0,01–0,015%).
- **Температура у камері:** **+18...+21 °C**, відносна вологість **85–90%**.
- **Вентиляція:** Провітрювання камери кожні 12 годин для видалення накопиченого CO₂ (концентрація CO₂ > 1% блокує дію етилену).
- **Результат:** 100% плодів одночасно стають яскраво-червоними за **3–4 доби**.

---

## 8.3. Параметри зберігання

| Стан плодів | Оптимальна температура | Відносна вологість | Термін зберігання |
| :--- | :--- | :--- | :--- |
| **Зелені плоди (Mature Green)** | **+13 ... +15 °C** | 85 – 90% | 21 – 28 діб |
| **Бланжеві плоди (Breaker)** | **+12 ... +14 °C** | 85 – 90% | 14 – 18 діб |
| **Червоні плоди (Fully Ripe)**| **+10 ... +12 °C** | 85 – 90% | 7 – 10 діб |

### 📌 СХЕМА 244: ЧОТИРИ СТАДІЇ СТИГЛОСТІ ТА КОМЕРЦІЙНА ЛОГІСТИКА

| Стадія | Забарвлення | Призначення |
| :--- | :--- | :--- |
| **Зелена (Mature Green)** | Сортистий розмір, гелем заповнені камери | **Далекий експорт** |
| **Бланжева (Breaker/Turning)** | Перша рожево-жовта пляма, **10–30%** поверхні | **Масовий комерційний збір** ✅ |
| **Рожева (Pink)** | 30–60% забарвлення | Локальний ринок |
| **Червона (Fully Ripe)** | 100% | Швидке споживання / переробка |

### 📌 СХЕМА 245: ДОЗАРЮВАННЯ ЕТИЛЕНОМ + РЕЖИМИ ЗБЕРІГАННЯ (Chilling Injury!)

| Параметр | Норма |
| :--- | :--- |
| **Етилен (C₂H₄)** | **100–150 ppm** (0,01–0,015%) |
| **Температура камери** | **+18...+21 °C**, RH **85–90%** |
| **Вентиляція** | Провітрювання кожні **12 год** (CO₂ > 1% блокує етилен!) |
| **Результат** | 100% червоних плодів за **3–4 доби** |

| Стан | t зберігання | RH | Термін |
| :--- | :--- | :--- | :--- |
| Mature Green | **+13...+15 °C** | 85–90% | 21–28 діб |
| Breaker | **+12...+14 °C** | 85–90% | 14–18 діб |
| Fully Ripe | **+10...+12 °C** | 85–90% | 7–10 діб |
| ⚠️ **Менше +10 °C** | **Chilling Injury:** руйнування судин, втрата аромату, альтернаріоз при нагріванні | — | заборонено |

> 📌 **Головний підсумок розділу:** Томат — клімактеричний плід із чіткою стадійною логістикою: зелена стиглість йде на далекий експорт, бланжева (10–30% поверхні) — оптимальна для масового комерційного збору, червона — лише для швидкого споживання. Масове дозарювання етиленом у герметичних камерах: 100–150 ppm, +18...+21 °C, RH 85–90%, провітрювання кожні 12 годин (CO₂ >1% блокує етилен) → 100% червоних за 3–4 доби. Критично: температура зберігання не нижче +10 °C — холод нижче +10...+12 °C руйнує судинну систему, знищує леткі аромати («водянистість») і відкриває ворота альтернаріозу.
