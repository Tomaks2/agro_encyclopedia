<Callout type="important" title="Біохімічна цінність томата: Лікопін">
Томат (*Solanum lycopersicum* L.) є головним джерелом **лікопіну (Lycopene — C₄₀H₅₆)** — потужного ліпофільного каротиноїдного антиоксиданту. Синтез лікопіну відбувається у хромопластах під час дозрівання плоду при температурі **+18...+26 °C**. При температурі вище **+30...32 °C** синтез лікопіну БЛОКУЄТЬСЯ, замість нього утворюється бета-каротин, і плід набуває не червоного, а жовто-помаранчевого забарвлення!
</Callout>

## 1.1. Геномна архітектура та морфологія рослини

<LightboxImage src="/photos/tomat/charts/45_shkala_BBCH_dlia_tomata.png" alt="Шкала BBCH для томата" />


Томат — диплоїдна самозапильна рослина родини Пасльонові (**2n = 24 хромосоми**).

```
                        Схема судинної анатомії куща томата
  
                     [ Верхівкова брунька / Китиця ]
                                   │
                    ┌──────────────┴──────────────┐
                    │      Пасинок (Side shoot)   │
                    │   (Видаляється в пазусі!)   │
                    └──────────────┬──────────────┘
                                   │
                           [ Скелетне стебло ]
                        (Провідна ксилема/флоема)
                                   │
                     ┌─────────────┴─────────────┐
                     │     Коренева система      │
                     │  (Стрижнево-мичкувата)    │
                     └───────────────────────────┘
```

1. **Коренева система:** Стрижнева при насіннєвому безрозсадному вирощуванні (заглиблюється до 1,5 м); потужно-мичкувата при розсадному пікіруванні (залягає у шарі 0–40 см).
2. **Тип суцвіття:** Завиткова китиця (проста, розгалужена або складна). Перша китиця у індетермінантних сортів закладається над 9–11-м листком, у детермінантних — над 5–7-м листком.

## 1.2. Шкала фенологічних фаз BBCH для томата

<LightboxImage src="/photos/tomat/charts/50_temperaturnyi_kontrol_likopinu.png" alt="Температурний контроль ліколіну" />


| Код BBCH | Фаза розвитку | Агротехнічний регламент |
| :--- | :--- | :--- |
| **BBCH 00–09** | Проростання насіння та поява сім'ядолей | Температура +22...+25 °C, вологість 85%. |
| **BBCH 11–19** | Розгортання справжнього листя розсади | Досвічування DLI 15–18 mol/m²/добу, зниження t до +16...+18 °C. |
| **BBCH 51–59** | Висунення суцвіть (поява першої китиці) | Посадка розсади на постійне місце, підв'язка до шпалери. |
| **BBCH 61–69** | Цвітіння (1-ша — 5-та китиці) | Початок пасинкування, обпилення (джмелі / вибрація шпалери). |
| **BBCH 71–75** | Зав'язування та ріст плодів | **Критична фаза №1:** Інтенсивне підживлення Кальцієм (CaCl2 / Ca-EDTA). |
| **BBCH 81–89** | Дозрівання плодів (Бланжева ──► Червона) | Внесення Калію (K₂O), контроль фітофторозу та совки. |

### 📌 СХЕМА 230: БІОХІМІЯ ЛІКОПІНУ: ТЕМПЕРАТУРНИЙ ПЕРЕМКАЧ ЗАБАРВЛЕННЯ

| Температура плоду | Результат синтезу | Колір плоду |
| :--- | :--- | :--- |
| **+18...+26 °C** | Лікопін (C₄₀H₅₆) синтезується у хромопластах | **Яскраво-червоний** |
| **> +30...32 °C** | Синтез лікопіну **БЛОКУЄТЬСЯ** → утворюється β-каротин | **Жовто-помаранчевий** |

**Механізм:** лікопін — ліпофільний каротиноїдний антиоксидант, що накопичується саме під час дозрівання; жовте «плечим» плоду влітку = пряма ознака температурного блокування.

### 📌 СХЕМА 231: КЛЮЧОВІ ПАРАМЕТРИ БІОЛОГІЇ ТОМАТА

| Параметр | Значення |
| :--- | :--- |
| **Геном** | Диплоїд **2n = 24**, самозапильний, родинна Solanaceae |
| **Корінь** | Стрижневий безрозсадний (до **1,5 м** глибини) / мичкуватий при пікіруванні (**0–40 см**) |
| **Перша китиця** | Індет. — над **9–11 листком**, дет. — над **5–7 листком** |
| **Тип суцвіття** | Завиткова китиця: проста, розгалужена, складна |
| **BBCH 71–75 (критична фаза №1)** | Зав'яз → інтенсивний **Ca** (CaCl₂ / Ca-EDTA) |

> 📌 **Головний підсумок розділу:** Томат (*Solanum lycopersicum*, 2n = 24) — самозапильна пасльонова з двома варіантами кореня (стрижневий до 1,5 м безрозсадний / мичкуватий 0–40 см після пікірування). Ключова біохімічна особливість — температурний контроль забарвлення: лікопін синтезується у хромопластах лише при +18...+26 °C, а вище +30...+32 °C блокується на користь β-каротину, даючи жовто-помаранчевий плід. Перша китиця закладається над 9–11 листком (індет.) або над 5–7 (дет.), а критична фаза №1 за BBCH (71–75) вимагає інтенсивного кальцію для запобігання вершинної гнилі.
