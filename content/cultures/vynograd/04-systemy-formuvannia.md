<Callout type="important" title="Мета формування">
Правильне формування куща винограду гарантує оптимальну освітленість листкового апарату (Photosynthetically Active Radiation — PAR > 80%), провітрюваність крони для запобігання грибковим хворобам, зручність механізованого догляду та нормоване навантаження вічками для отримання врожаю заданої якості.
</Callout>

## 4.1. Вертикально-шпалерна посадка (VSP — Vertical Shoot Positioned)

VSP є світовим стандартом для промислових та аматорських виноградників. Пагони спрямовуються строго вертикально між парами рухомих дротів.

```
                           Схема формування VSP на 4 дроти
                          
      Дріт 4 (Верхній)    ═════════════════════════════════════════════  [2.0 м]
                                  │           │           │
      Дріт 3 (Подвійний)  ───────┼───────────┼───────────┼───────────  [1.6 м] (Пагони)
                                  │           │           │
      Дріт 2 (Подвійний)  ───────┼───────────┼───────────┼───────────  [1.2 м] (Пагони)
                                  │   Грони   │   Грони   │
      Дріт 1 (Плодоносний) ═══════╧═══════════╧═══════════╧═══════════  [0.8 м] (Лоза)
                                              ║
                                              ║ (Штамб)
                                       ═══════╩═══════  [Ґрунт]
```

### Параметри шпалери VSP:
- **Висота стовпів:** 2.2–2.5 м (над землею 1.8–2.0 м)
- **Відстань між кущами:** 1.0–1.5 м
- **Відстань між рядами:** 2.0–2.5 м
- **Навантаження:** 12–18 пагонів на кущ
- **Застосування:** Столові та технічні сорти у всіх зонах України.

## 4.2. Одноплечий та Двоплечий Гюйо (Guyot System)

Система Гюйо — це класичне безштамбове або низькоштамбове формування, яке ідеально підходить для **укривного виноградарства** у зонах із ризиком зимових морозів.

```
                        Двоплечий Гюйо (Guyot Double)
                       
                 Плодова стрілка (8-10 вічок)    Плодова стрілка (8-10 вічок)
                 ◄─────────────────────────┐  ┌─────────────────────────►
                                           │  │
                                      ┌────┴──┴────┐
                                      │ Сучки замі-│
                                      │ щення (2в) │
                                      └─────┬──────┘
                                            │ (Низький штамб 20-30 см)
                                     ═══════╩═══════ [Ґрунт]
```

### Принцип роботи за системою Гюйо:
- Кожного року восени повністю зрізають відплодоношену плодову стрілку.
- Із двох пагонів, що виросли на сучку заміщення, верхній обрізають довго (на плодово-стрілковий пагін, 8–12 вічок), а нижній — коротко (на новий сучок заміщення, 2–3 вічка).
- **Перевага:** Легко притискається до землі для осіннього укриття!

## 4.3. Кордон Руайя (Cordon de Royat)

Постійне горизонтальне формування із багаторічним рукавом, на якому розміщені ріжки (рожки) із короткими сучками обрізки (2–3 вічка).

<InfoBlock type="gold" icon="🏛️" title="Особливості Кордону Руайя">
- **Переваги:** Високий запас багаторічної деревини забезпечує велику масу ягід та стійкість до стресів (посуха). Ідеальний для технічних сортів (Каберне, Мерло, Шардоне).
- **Недоліки:** Важко укривати на зиму. Використовується суто у неукривній зоні Півдня України та Закарпаття.
</InfoBlock>

## 4.4. Чашоподібне формування (Gobelet / Bush Vine)

Старовинне безштамбове або низькоштамбове формування у вигляді чаші без використання шпалери.

- **Схема:** Кущ має 3–5 рукавів, що розходяться в боки від центру. Кожен рукав закінчується рожком із короткою обрізкою (2 вічка).
- **Переваги:** Мінімальні витрати на шпалеру та дріт. Стійкість до сильни вітрів.
- **Недоліки:** Низька продуктивність праці, механізація ускладнена.

---

## 4.5. Бельгійська арка та Альтанка (Verandah / Pergola)

Високоштамбове аркове формування для присадибних ділянок, альтанок та тентів.

- **Висота штамба:** 1.8–2.5 м
- **Переваги:** Максимальне використання сонячної енергії, економія площі ділянки, висока врожайність (до 50–100 кг з куща!).
- **Вимоги:** Застосовується ТІЛЬКИ для морозостійких сортів (-25...-30 °C), які не потребують укриття на зиму (Юпітер, Кристал, Ізабелла).
