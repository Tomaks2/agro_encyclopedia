<Callout type="important" title="Золоте правило обрізки">
Виноградна лоза плодоносить **виключно на пагонах поточного року, що виросли з вічок на однорічній визрілій лозі**, яка, у свою чергу, сидить на дворічній деревині! Обрізка регулює баланс між вегетативним ростом пагонів та генеративним навантаженням ягодами.
</Callout>

## 5.1. Зимова обрізка та розрахунок навантаження вічками

Зимову обрізку проводять після опадання листя (листопад) у неукривній зоні або ранньою весною (березень) до початку сокоруху.

### Закони довжини обрізки плодових стрілок:
1. **Коротка обрізка (2–4 вічка):** Для сортів із високою плодоносністю нижніх вічок (технічні сорти, винні).
2. **Середня обрізка (5–8 вічок):** Універсальна для більшості столових сортів.
3. **Довга обрізка (9–14 вічок):** Для великогронних сортів (Аркадія, Преображення, Кишмиш Лучистий), у яких нижні 2–3 бруньки є слабоплодоносними.

### Формула розрахунку навантаження вічками (Закон Гуатера):


*Формула:* N = Y_план / (m_грона * K_плод * K_перез)

Де:
- N — кількість вічок, що залишають при обрізці;
- Y_план — запланований урожай з куща (кг);
- m_грона — середня маса грона сорту (кг);
- K_плод — коефіцієнт плодоносності (зазвичай 1.2–1.6);
- K_перез — коефіцієнт перезимівлі бруньок (0.8–0.95).

## 5.2. Зелені операції (Операції з вегетуючими пагонами)

Зелені операції є найважливішим інструментом агротехніки протягом травня–серпня.

```
                         Календарний графік зелених операцій
                        
  Травень (BBCH 15-53)  ──► [ 1. Нормування пагонів (Уламування «двійників») ]
                                           │
  Червень (BBCH 57-68)  ──► [ 2. Перша підв'язка + Видалення пасинків ]
                                           │
  Липень (BBCH 71-77)   ──► [ 3. Нормування врожаю гронами (1-2/пагін) ]
                                           │
  Серпень (BBCH 81-85)  ──► [ 4. Чеканка пагонів (Зрізання верхівок 20 см) ]
                                           │
  Серпень (BBCH 85-89)  ──► [ 5. Освітлення грон (Обривання 3-4 листків) ]
```

### 1. Уламування зелених пагонів (Ноткування):
Проводять при досягненні пагонами довжини **10–15 см**. Видаляють усі порожні (безсуцвітні) пагони біля основи куща, волчки на багаторічній деревині (якщо вони не потрібні для омолодження рукавів) та слабші пагони-двійники з одного вічка.

### 2. Пасинкування (Видалення бокових пагонів II порядку):
Пасинки виснажують кущ та затіняють гніздо. 

<InfoBlock type="gold" icon="✂️" title="Правило пасинкування">
Категорично заборонено виламувати пасинок «на кільце» повністю біля основи — це пошкоджує зимуюче вічко у пазусі листка! Пасинок **прищипують, залишаючи 1–2 нижніх листки**.
</InfoBlock>

### 3. Чеканка пагонів (Карбування):
Проводять у серпні, коли пагони уповільнюють ріст, а їхні верхівки розпрямляються. Верхівки пагонів відсікають на **20–30 см** (над 14–16-м листком). Це зупиняє ростові процеси та спрямовує всі пластичні речовини на налив ягід та визрівання лози.

### 4. Освітлення грон (Дефоліація гронової зони):
За 2–3 тижні до збору врожаю видаляють **3–5 нижніх листків**, що прикривають грони від сонця. Це покращує провітрюваність, підвищує вміст цукру та інтенсивність забарвлення ягід (антоціановий синтез).
