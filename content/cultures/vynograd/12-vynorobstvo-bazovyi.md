<Callout type="important" title="Філософія виноробства">
Виноробство — це мистецтво контрольованої мікробіологічної ферментації цукрів виноградного сусла у етиловий спирт за допомогою дріжджів *Saccharomyces cerevisiae*. Головне правило чистого виноробства — **абсолютна стерильність обладнання** та захист сусла від окислення киснем повітря за допомогою діоксиду сірки (SO_2).
</Callout>

```
                       Технологічна схема виготовлення вин
                      
             [ Свіжозібраний виноград ]
                         │
                         ▼
        [ Гребневідділення та Дроблення ]
                         │
        ┌────────────────┴────────────────┐
        │                                 │
 [ Біла схема ]                    [ Червона схема ]

        │                                 │
        ▼                                 ▼

        │                                 │

        │                          [ Пресування мезги ]
        │                                 │
        └────────────────┬────────────────┘

             [ Перша зняття з осаду (Racking) ]
                         │
                         ▼
             [ Видозрівання та Зберігання ]
```

## 12.2. Порівняння Білої та Червоної схем виноробства

| Технологічний етап | Біла схема (Вина з білих сортів) | Червона схема (Вина з червоних сортів) |
| :--- | :--- | :--- |
| **Пресування** | Негайно після дроблення (відділення сусла від шкірки) | Після завершення бродіння та мацерації! |
| **Температура бродіння** | **+15...+18^°C** (збереження тонких фруктових ароматиків) | **+22...+28^°C** (екстракція антоціанів та танінів) |
| **Контакт із шкіркою** | Відсутній або мінімальний (кріомацерація 4–6 год при +5^°C) | Повний (7–15 днів під час бродіння) |
| **Робота з шапкою** | Відсутня | Обов'язкова! (Пижаж — занурення / Ремонтірування — перекачування 3-4 р/день) |
| **Колір та структура** | Солом'яно-жовтий, свіжа кислотність | Інтенсивно-рубіновий, танінна структура |

## 12.3. Сульфітація (SO_2) та контроль чистоти

Діоксид сірки (SO_2) — універсальний антиоксидант та антисептик у виноробстві:

<InfoBlock type="gold" icon="🧪" title="Норми сульфітації (SO₂)">
1. **При дробленні ягід:** Вносять Піросульфіт Калію (K_2S_2O_5) з розрахунку **1–1.5 г на 10 кг мезги** (що дає 50... 75 мг/л  SO_2). Це пригнічує дикі дріжджі (*Kloeckera apiculata*) та бактерії, захищаючи сусло від потемніння.
2. **Внесення ЧКД (Чистих Культур Дріжджів):** Через 2–4 години після сульфітації вносять селекціоновані сухі дріжні *Saccharomyces cerevisiae* (2 г на 10 л), розводячи їх у теплій воді (+35... +38^°C) з цукром.
3. **Первинне бродіння:** Триває 7–14 днів до повного зброджування цукру (< 2 г/л цукру = сухе вино).
</InfoBlock>
