<Callout type="important" title="Контроль кондицій ягід">
Виноград належить до **ненеклімактеричних плодів** — після зрізання з куща ягоди зупиняють накопичення цукрів та дозрівання! Збір слід проводити строго у момент досягнення оптимальної кондиційної стиглості (кондиції залежать від призначення: столовий, біле виноматеріал, червоне виноматеріал, коньячні спирти).
</Callout>

## 11.1. Показники та кондиції технічної стиглості

Для точного визначення дати збору лабораторно оцінюють 4 ключових параметри:

```
                   Аналітичний контроль стиглості винограду
                  
    ┌──────────────────────────┐         ┌──────────────────────────┐
    │ 1. Цукристість (Brix)   │         │ 2. Титрована кислотність │
    │   Вимірюється оптичним   │         │    (TA, г/л)             │
    │   рефрактометром         │         │    Титрування NaOH       │
    └────────────┬─────────────┘         └────────────┬─────────────┘
                 │                                    │
                 └───────────────────┬────────────────┘
                                     │
    ┌──────────────────────────┐     │   ┌──────────────────────────┐
    │ 3. Активна кислотність   ├─────┴───┤ 4. Зрілість танінів     │
    │    (pH сусла)            │         │    (Фенольна стиглість)  │
    │    рН-метр               │         │    Тест на кісточки      │
    └──────────────────────────┘         └──────────────────────────┘
```

### Кондиції ягід залежно від напрямку використання:

| Напрямок використання | Вміст цукру (°Brix) | Титрована кислотність (TA, г/л) | pH сусла | Ознаки стиглості кісточок |
| :--- | :--- | :--- | :--- | :--- |
| **Столовий виноград** | **15 – 18° Brix** | 5.0 – 6.5 г/л | 3.4 – 3.6 | Зелено-коричневі, легко відокремлюються |
| **Ігристі виноматеріали** | **17 – 19° Brix** | 8.0 – 10.0 г/л | 2.9 – 3.1 | Зеленкуваті, висока яблучна кислота |
| **Білі тихі вина** | **19 – 22° Brix** | 6.5 – 8.0 г/л | 3.1 – 3.3 | Світло-коричневі, аромат сорту |
| **Червоні сухі вина** | **22 – 25° Brix** | 5.5 – 7.0 г/л | 3.4 – 3.6 | **Темно-коричневі, хрусткі, без гіркоти** |
| **Десертні / Кріплені** | **> 25° Brix** | 4.5 – 6.0 г/л | 3.6 – 3.8 | Зв'ялені ягоди |

<InfoBlock type="gold" icon="⚖️" title="Індекс Ravaz (Раваза)">
Індекс Ravaz характеризує баланс між урожаєм та вегетативною масою:

*Формула:* Індекс Ravaz = Урожай ягід з куща (кг)Маса обрізаної лози взимку (кг)

Ідеальне значення для якісного виноробства становить **5.0... 8.0**. Якщо індекс > 10, кущ перевантажений (вино буде плоским), якщо < 3 — кущ жирує.
</InfoBlock>

## 11.2. Правила селективного збирання ягід

1. **Час збору:** Збір проводять у суху погоду у **ранкові години (від 6:00 до 11:00)**, поки ягоди прохолодні (t^° < +18^°C). Це зменшує ризик самовільного спонтанного бродіння та окислення ароматичних сполук.
2. **Селекція (Сортування):** Зрізають грони секатором із короткою ніжкою. Грони із проявами сірої гнилі, оїдіуму або пошкодженнями осами зрізають окремо і НЕ змішують із кондиційним урожаєм.
3. **Транспортування:** Для винних сортів використовують малі пластикові ящики ємністю **15–20 кг** з перфорацією. Використання глибоких кузовів (> 40 см) призводить до самодавкання ягід, витікання сусла та окислення!
