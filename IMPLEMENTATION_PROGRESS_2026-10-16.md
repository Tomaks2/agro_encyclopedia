# Прогрес реалізації Agro Encyclopedia — 2026-10-16

## Виконано

### Архітектура та маршрути

- Англійську локаль прибрано з публічної генерації: production routing залишено лише для `uk`.
- Невідомі локалі не рендеряться через locale layout.
- `/en` і `/en/catalog` перевірені у preview: повертають `404`, а не український контент під англійською URL.
- `NextChapter` отримав locale-aware нормалізацію старих filename-посилань.
- Усі перевірені внутрішні NextChapter-переходи приведені до canonical metadata slug.
- Виправлено підтверджені биті переходи seed-серії та cross-catalog перехід до кукурудзи.
- Із metadata винограду прибрано відсутній файл `28-generation-prompts.md`; кількість секцій приведено до фактичних 27.

### Каталог

- Насінництво отримало власну категорію `seed`, а не потрапляє до овочів через fallback.
- До metadata насінництва додано `kind: seed-production` і `category: seed`.
- Невідомий slug у каталозі більше не класифікується мовчки як овочевий: він потрапляє до `special`.
- Додано категорію «Спеціальні довідники».

### Візуальна система та контент

- На мобільних ширинах громіздкий sidebar приховується; замість нього показується компактна навігація з back-link і згортаним змістом розділу.
- `HeroCover` має fallback для відсутнього або битого зображення, тому сторінка не показує порожній/битий image box.
- Публічну таблицю винограду переведено із застарілого `ComparisonTable` на GFM Markdown table.
- Footer-посилання `/search`, якого не існувало, замінено на trigger фактичного пошукового overlay.

1. Повністю довести `npm run lint` до нуля: зараз у репозиторії залишаються попередні lint-помилки в legacy diagrams, scripts і частині компонентів.
2. Перевірити всі HeroCover-шляхи й замінити повторне томатне зображення на тематичні обкладинки для груп насінництва.
3. Винести нумерацію `order` і редакційний `chapterNumber` у metadata, щоб UI не використовував `i + 1`.
4. Прибрати редакторські артефакти з опублікованого каталогу та розділити public content і internal reports.
5. Уніфікувати Callout/InfoBlock props і завершити CSS-модернізацію таблиць.
6. Провести ручний screenshot-аудит desktop/mobile після фінального контентного прибирання.
