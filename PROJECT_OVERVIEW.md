# ПРОЄКТ: Агро-Енциклопедія "Садівництво від А до Я"

## 1. Концепція та Амбіції
Цей проєкт створений з метою переосмислити формат подачі сільськогосподарської інформації. Ми відійшли від сухих радянських підручників та нудних полотен тексту. Наша амбіція — створити **найкращу, найсучаснішу та найбільш інтерактивну агро-енциклопедію у світі**. 

Ми будуємо **"Золотий стандарт"** (починаючи з культури "Груша", яка слугує еталоном для всіх інших), де кожен елемент працює на розуміння: не просто зазубрювання фактів, а глибоке усвідомлення фізіології дерева, процесів росту та сучасних методів догляду.

## 2. Технологічний Стек
Проєкт розробляється з використанням найсучасніших веб-технологій:
- **Фреймворк:** Next.js (App Router, Turbopack)
- **Мова програмування:** TypeScript
- **Стилізація:** Vanilla CSS (глобальні змінні `globals.css` для дизайн-системи), інлайн-стилізація в кастомних компонентах
- **Контент:** MDX (Markdown з підтримкою React-компонентів) — дозволяє інтегрувати складну логіку та інтерактивні схеми прямо в текст.
- **Анімації:** Framer Motion (використовується в інтерактивних тренажерах та схемах)
- **PWA (Progressive Web App):** Використання Serwist для підтримки роботи в офлайні та кешування, що критично для використання довідника прямо в саду.

## 3. Дизайн та Стилістика (UI/UX)
Ми робимо ставку на преміальний, чистий та сучасний дизайн (Glassmorphism, плавні тіні, градієнти, мікро-анімації):

### 3.1. Типографіка
- **Шрифти:** Roboto / Inter (через змінні `var(--font-sans)`) для зручності читання, `var(--font-serif)` для заголовків.
- Заголовки (H2, H3) в MDX-файлах чітко структуровані для автоматичної генерації навігації.

### 3.2. Кольорова Палітра (Nature-Inspired)
- Основні кольори: Темно-зелений (Primary), Теплий деревний (Bark), Золотисто-жовтий (Accent/Amber).
- Кольори розроблено так, щоб вони гармонійно виглядали, не втомлювали очі та асоціювалися з природою.

### 3.3. Використані Компоненти та Елементи
Усі MDX-файли будуються як конструктор з кастомних React-компонентів:
- `<HeroCover>`: Преміальний банер на початку кожного розділу з великим фото та заголовком.
- `<TableOfContents>`: Автоматична навігація, яка збирає H3-заголовки.
- `<Callout>`: Блоки з порадами, попередженнями та важливою інформацією. Виділені кольором, градієнтами та **курсивом**.
- `<InfoBlock>`: Аналог Callout, але з іншим візуальним стилем для різноманітності.
- `<EditorialDivider>`: Елегантний розділювач секцій.
- `<PullQuote>`: Виділені цитати для ключових тез.
- `<PremiumProcess>`: Складний компонент для відображення послідовних кроків (наприклад, алгоритм обробки чи обрізки) зі з'єднувальними лініями.
- **Інтерактивні тренажери:** `<BranchAngleDiagram>`, `<TreeLifespanDiagram>`, `<RootSystemDiagram>` — візуальні інструменти, де користувач може рухати повзунок і бачити результат.

## 4. Виконана Робота та Статус
Ми успішно впровадили та відполірували 13 розділів для культури **Груша** (наш "Золотий стандарт"), а також повністю завершили текстову, структурну та компонентну інтеграцію 11 розділів для культури **Яблуня**.

**Що зроблено:**
1. **Текстовий контент:** Повністю вичитано, структуровано та переведено у формат MDX розділи про Грушу (13 розділів) та Яблуню (11 розділів).
2. **Інтеграція Медіа (Груша):** Використано 32 локальних медіафайли, підключено графіку. *(Примітка: для Яблуні інтеграція фото ще в процесі).*
3. **Редакторська правка:** Уніфіковано термінологію, стандартизовано використання тире.
4. **Виправлення багів:** Вирішено проблему з дублюванням заголовків H2, полагоджено кешування PWA (Serwist), усунуто помилки Typescript при білді.
5. **Інтерактивні схеми:** Вибудована наскрізна нумерація схем (СХЕМА 1, 2, 3...) в межах культур. 
6. **Удосконалення Дизайн-Системи (Правила використання):** 
   - Додано курсив (`fontStyle: 'italic'`) до параграфів всередині `<Callout>` та `<InfoBlock>`.
   - **ВАЖЛИВЕ ПРАВИЛО (СУВОРО):** Компоненти `<PremiumProcess>` та `<ComparisonTable>` ПОВНІСТЮ ЗАБОРОНЕНІ до використання через неуграбний вигляд та баги рендерингу на мобільних пристроях.
   - **ВАЖЛИВЕ ПРАВИЛО (ТАБЛИЦІ):** Усі таблиці реалізуються ВИКЛЮЧНО через чисті стандартні Markdown-таблиці (`| Заголовок 1 | Заголовок 2 |`). Вони стилізуються класичними класами `.prose-table` із плавною тач-прокруткою.
   - **ВАЖЛИВЕ ПРАВИЛО (АЛГОРИТМИ):** Для покрокових процесів слід використовувати чисті нумеровані списки всередині `<InfoBlock type="gold" icon="..." title="...">`.
   - Всі підрозділи в MDX обов'язково повинні мати маркер заголовка (`###` або `##`), щоб застосовувалися глобальні стилі для заголовків.

## 5. Наступні Кроки
1. **Яблуня (Фіналізація медіа):** Додати пропущені фотографії у відповідні розділи про Яблуню (замінити пусті картинки, додати фото в шапки розділів, наприклад, фото шкідників).
2. **Персик:** Масштабування "Золотого стандарту" на культуру "Персик".
3. Заміна старих ASCII-схем або статичного тексту на нові преміальні React-компоненти для розділів про Персик (чітко дотримуючись нових правил використання компонентів).
4. Подальше покращення мобільної версії та швидкодії роботи PWA в офлайн-режимі.

# ЗОЛОТЕ ПРАВИЛО РОБОТИ (АБСОЛЮТНИЙ ПРІОРИТЕТ)

1. **Якість важливіша за швидкість.** Ніколи не поспішай. Роби довго, але роби ідеально з першого разу.
2. **Тотальний самоконтроль:** Перед тим як здати роботу, перевір кожну літеру, кожне посилання на фото, кожне речення, чи кожна картинка існує, чи правильне форматування.
3. **Без багів:** Виключити створення багів або помилок, щоб не витрачати час на їхнє виправлення. Кожен рядок має бути підігнаний під еталони.
4. Якщо є сумніви — краще перевірити ще раз. Зробив швидко і криво = провал. Зробив повільно і ідеально = успіх.
