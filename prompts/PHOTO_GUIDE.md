# 📸 ПРАВИЛА РОБОТИ З ФОТО ТА ІЛЮСТРАЦІЯМИ (PHOTO GUIDE)

Контент в АгроЕнциклопедії повинен бути максимально наочним. 

Завжди комбінуйте три типи візуалізації:

## 1. Реальні фотографії (Найкраще для хвороб, шкідників, сортів)

Для того, щоб садівник міг точно впізнати проблему чи сорт, потрібні реальні фотографії. 
Оскільки ми не можемо автоматично завантажити всі фото, найкраща практика — **використовувати прямі посилання на Wikimedia Commons**.

**Як робити:**
- Знайдіть якісне фото у Вікіпедії або Wikimedia.
- Скопіюйте пряме посилання на зображення (`.jpg` або `.png`).
- Вставте у Markdown з чітким підписом.

```markdown
![Яблунева плодожерка (Cydia pomonella)](https://upload.wikimedia.org/wikipedia/commons/e/ec/Cydia_pomonella_macro.jpg)
```

## 2. Текстові ASCII-Схеми (Найкраще для простих концепцій)

Якщо треба показати принципову будову, графік обробок чи прості типи обрізки — малюйте схему безпосередньо текстом. Вона завжди завантажиться миттєво і працюватиме офлайн.

Використовуйте символи: `━ ┃ ╭ ╰ ┴ ┬ ├ ┤ 🌿 ✂️ 🍎 🐛`

**Як робити:**
Обертайте схему у блок з мовою `text`.

## 3. Промти для нейромереж (Найкраще для складних ілюстрацій)

Якщо процес надто складний для ASCII-схеми, але реальне фото не дає повного розуміння (наприклад, методи щеплення в розрізі, або кут зрізу при обрізці), система повинна запросити створення такої ілюстрації.

**Як робити:**
У Markdown-файлі створіть виділений блок, де опишете детальний промт для генерації такого зображення. Користувач пізніше згенерує його через Midjourney, DALL-E або Stable Diffusion і вставить у папку `photos/`.

**Приклад у тексті розділу:**

```markdown
> 🎨 **ПРОМТ ДЛЯ ІЛЮСТРАЦІЇ (Щеплення "За кору"):** 
> "Схематичний розріз товстої гілки (підщепи), кора якої надрізана і злегка відігнута. Під кору вставлений тонкий живець (прищепа) зі зрізом під кутом 30 градусів. Максимально деталізовано показано з'єднання камбіальних шарів. Стиль: сучасна векторна ботанічна ілюстрація, ізометрична проекція, білий фон, кольори: відтінки зеленого та коричневого."

Після генерації, збережіть файл як `scheplennia-za-koru.png` у папку `photos/` та розкоментуйте наступний рядок:
<!-- ![Схема щеплення за кору](photos/scheplennia-za-koru.png) -->
```
# ЗОЛОТЕ ПРАВИЛО РОБОТИ (АБСОЛЮТНИЙ ПРІОРИТЕТ)

1. **Якість важливіша за швидкість.** Ніколи не поспішай. Роби довго, але роби ідеально з першого разу.
2. **Тотальний самоконтроль:** Перед тим як здати роботу, перевір кожну літеру, кожне посилання на фото, кожне речення, чи кожна картинка існує, чи правильне форматування.
3. **Без багів:** Виключити створення багів або помилок, щоб не витрачати час на їхнє виправлення. Кожен рядок має бути підігнаний під еталони.
4. Якщо є сумніви — краще перевірити ще раз. Зробив швидко і криво = провал. Зробив повільно і ідеально = успіх.
