## ✍️ Як додати нову культуру (без програмування!)

### 1. Прочитай промти

Перед тим як писати — відкрий файл `prompts/MASTER_PROMPT.md`. Там є готовий промт для ШІ який генерує контент у правильному форматі.

### 2. Створи папку

```
content/cultures/НАЗВА_КУЛЬТУРИ/
├── meta.json          ← скопіюй з yablunia/ і відредагуй
├── 01-назва.md
├── 02-назва.md
└── photos/
```

### 3. Заповни meta.json

Відкрий `content/cultures/yablunia/meta.json` як приклад і скопіюй структуру. Змініть:
- `slug` — латинська назва культури (наприклад: `"personyk"`)
- `emoji`, `color`, `colorLight`
- `uk.name`, `uk.description`, `en.name`
- `sections` — список розділів з їх slug та filename

### 4. Напиши контент

Кожен розділ — окремий `.md` файл. Дотримуйся стилю з `prompts/CONTENT_STYLE_GUIDE.md`.

### 5. Готово!

Сайт автоматично підхопить нову культуру при наступному запуску. **Програмування не потрібне.**

## 🖼️ Фото та схеми

Детальні правила у `prompts/PHOTO_GUIDE.md`. Коротко:

| Тип зображення | Рішення |
|----------------|---------|
| Хвороби, шкідники, сорти | Посилання на Wikimedia з підписом |
| Схема обрізки, щеплення, посадки | Детальний промт для Midjourney/DALL-E у файлі |
| ASCII-схема будови | Малюємо текстом прямо у MD |
| Фото готової ілюстрації | `![підпис](photos/назва.png)` |

## 🚀 Деплой на Vercel

Детальна інструкція: `docs/DEPLOY.md`

Коротко:
1. Завантажте код на GitHub
2. Зайдіть на vercel.com → "New Project" → виберіть репозиторій
3. Натисніть Deploy — готово!

Після деплою сайт буде доступний на безкоштовному домені `*.vercel.app`.
