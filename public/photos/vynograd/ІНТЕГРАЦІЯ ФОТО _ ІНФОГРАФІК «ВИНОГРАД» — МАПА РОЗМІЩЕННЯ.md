Цей файл — покрокова інструкція, куди покласти ваші готові фото та схеми і який код вставити в кожен розділ бази знань «Виноград» на сайті agro-encyclopedia.vercel.app. Усі 54 інфографіки (СХЕМИ 1–54) мають точну прив'язку до файлу-розділу та місця вставки.

## 1. Загальне правило розміщення

Усі фото винограду кладуться в одну папку репозиторію:

```
public/photos/vynograd/
```

Якщо папки ще немає — створіть її. Далі кожний файл називається за шаблоном:

```
vyn_heroshot_NN.png        — фото-обкладинка розділу NN (HeroCover)
vyn_skhema_NN.png          — інфографіка «СХЕМА NN»
vyn_rozdel_NN_nazva.png    — довільні додаткові фото розділу NN
```

Зверніть увагу: назви файлів — латиницею, без пробілів, зі знаком підкреслення. Так робить сайт (приклад у яблуні — `Розділ_1_...`, але для винограду краще короткі латинські назви, щоб не ламались URL).

Згадка в розділі — один рядок одразу після СХЕМА-заголовка/таблиці:

```html
<LightboxImage src="/photos/vynograd/vyn_skhema_01.png" alt="СХЕМА 1: Всесвіт винограду — три географічні групи та їхня роль" />
```

**Важливо:** LightboxImage береться з MDX-компонентів автоматично (`import { LightboxImage } from '@/components/mdx'`), спеціально реєструвати не треба — компонент уже підключений у MDX-парсері сайту (у яблуні використовується без додаткових імпортів, рядки типу 13 у `01-botanika.md`).

## 3. Файли формату PNG/JPG — рекомендації

Перед завантаженням переконайтесь, що файли відповідають таким вимогам: формат PNG або JPG; ширина не менше 1200 px (для інфографік — 1600 px і більше); розмір файлу до 2 МБ (Next.js + Vercel добре відображають і більші, але швидше — менші); фон білий або світлий (під стиль сайту). Назви — без пробілів та кирилиці (латиниця, дефіс або підкреслення).

## 4. Як інтегрувати покроково (для сайту)

1. У локальній копії репозиторію створіть папку `public/photos/vynograd/`.
2. Скопіюйте всі фото туди з назвами з таблиць вище.
3. Відкрийте відповідний MD-файл розділу (шлях: `content/cultures/vynograd/`).
4. Знайдіть заголовок `### 📊 СХЕМА NN` та таблицю під ним — вставте `<LightboxImage ... />` одразу після таблиці (перед наступним заголовком або абзацом).
5. Збережіть файл, запуште на GitHub — Vercel автоматично пересобере сайт, і фото з'являться.

Якщо якийсь фото-файл має іншу назву, ніж у таблиці — або перейменуйте його під таблицю, або змініть `src="..."` у коді вставки на свою назву.

## 5. Фото-обкладинки розділів (HeroCover)

Якщо у вас є окремі фото для обкладинок розділів (грона, виноградник, вино), кладіть їх так само в `public/photos/vynograd/` з назвами `vyn_heroshot_NN.png`, де NN — номер розділу. Вставка в MDX виглядає так (приклад для розділу 01):

```html
<HeroCover
  title="ВСЕСВІТ ВИНОГРАДУ"
  subtitle="Ампелографія, систематика, вісім тисячоліть культури"
  chapterNum="01"
  nextSlug="/uk/vynograd/biolohiya-lozy"
  chapterName="Біологія лози"
  imageSrc="/photos/vynograd/vyn_heroshot_01.png"
/>
```

Параметри `title`, `subtitle`, `chapterNum`, `nextSlug`, `chapterName` беріть із самого MDX-файлу (рядок `<HeroCover ... />` на початку). Додайте лише `imageSrc="..."` у цей виклик — компоненти сайту підтримують цю пропсу.

## 6. Перевірка після інтеграції

Після пушу перевірте на сайті: www.agro-encyclopedia.vercel.app/uk/vynograd. Фото має відкриватися на повний екран при кліку (Lightbox-ефект), а підпис `alt` — відображатись під зображенням. Якщо фото не з'явилось — найчастіша причина: помилка в назві файлу (пробіл/кирилиця/регістр) — сверте назву в `public/photos/vynograd/` з `src="..."` у коді.
